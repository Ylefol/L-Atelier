sample_sheet.R:
---------------
HORIZON_create_sample_sheet(output_path = NULL, n_samples = 1)
  - Generates a CSV template with all required columns
  - Returns data.frame invisibly; writes to disk if output_path provided
  - Columns: sample_id, fastq_r1, fastq_r2, paired_end, output_dir,
    strandedness, condition

HORIZON_validate_sample_sheet(path, check_files = TRUE)
  - Reads CSV or accepts data.frame
  - Checks required columns, unique sample IDs, valid strandedness values
  - Checks FASTQ file existence (set check_files=FALSE if drive not mounted)
  - Returns validated sample sheet data.frame

build_index.R:
--------------
HORIZON_build_index(basename, reference, memory=8000, index_split=TRUE,
                    gapped=TRUE, force=FALSE, ...)
  - Wraps Rsubread::buildindex()
  - Skips build if index files already exist at basename (force=FALSE default)
  - force=TRUE overwrites existing index
  - index_split=TRUE reduces per-alignment RAM at cost of slight speed
  - memory parameter controls RAM during build (default 8 GB)

qc_trim.R:
----------
HORIZON_run_qc_trim(sample_sheet, sample_id, threads=4, compression=4,
                    adapter_r1=NULL, adapter_r2=NULL, ...)
  - Wraps Rfastp::rfastp() — QC + trimming in one pass
  - Auto-detects adapters (PE: overlap analysis; SE: built-in list)
  - Writes trimmed FASTQs + HTML/JSON report to <output_dir>/<sample_id>/qc/
  - Returns list: trimmed_r1, trimmed_r2, report_html, report_json

align.R:
--------
HORIZON_run_align(sample_sheet, sample_id, index, use_trimmed=TRUE,
                  threads=4, max_mismatches=3, ...)
  - Wraps Rsubread::align() with type="rna" (splice-aware)
  - use_trimmed=TRUE reads from qc/ subfolder; FALSE reads raw FASTQs
  - Writes unsorted BAM to <output_dir>/<sample_id>/aligned/
  - Pass to HORIZON_sort_index_bam() before counting

bam_processing.R:
-----------------
HORIZON_sort_index_bam(sample_sheet, sample_id, threads=4,
                       memory_per_thread=2000, remove_unsorted=TRUE)
  - Wraps Rsamtools::sortBam() + indexBam()
  - Total sort RAM ~ memory_per_thread * threads MB
  - Removes unsorted BAM by default (remove_unsorted=FALSE to keep)
  - Writes <sample_id>_sorted.bam + .bai index

bigwig.R:
---------
HORIZON_bam_to_bigwig(sample_sheet, sample_id, effective_genome_size,
                      threads=4L, bin_size=10L,
                      ignore_for_normalization=c("X","M"),
                      ignore_duplicates=TRUE, extend_reads=TRUE)
  - Wraps deeptools bamCoverage (must be on PATH)
  - RPKM normalisation; bin_size=10 matches bamCoverage default
  - effective_genome_size: numeric value OR assembly name string
    Built-in: "GRCh38" (2913022398), "GRCm38" (2652783500),
              "WBcel235" (100272607), "T2TCHM13" (3117292070)
  - ignore_for_normalization: use c("chrX","chrM") for UCSC-style genomes
  - Writes <sample_id>_RPKM.bw alongside the BAM in aligned/
  - Checks PATH for bamCoverage and BAI index before running

rename_chromosomes.R:
---------------------
HORIZON_rename_chromosomes(sample_sheet, sample_id, chr_map, file_suffix,
                           overwrite=FALSE, rename_suffix="_chrrenamed")
  - Scans output_dir/sample_id/ recursively for files ending with file_suffix
  - Renames chromosome identifiers according to chr_map for each matched file
  - file_type derived from file_suffix extension (bam/bed/bw)
  - chr_map: named character vector (old->new), path to 2-col TSV, or
    "T2TCHM13" for built-in T2T-CHM13v2.0 NCBI-to-UCSC map (NC_060925.1->chr1
    through NC_060948.1->chrY + NC_012920.1->chrM)
  - file_suffix: trailing filename fragment to match, e.g. "RPKM.bw"
  - BAM: rewrites @SQ SN: header fields via samtools reheader + re-indexes
  - BED: line-by-line replacement of column 1; preserves header/comment lines
  - BigWig: rtracklayer import -> renameSeqlevels -> export
  - overwrite=FALSE: output written with rename_suffix before extension
  - Returns character vector of output paths invisibly

count.R:
--------
HORIZON_run_count(sample_sheet, sample_id, annotation, feature_type="exon",
                  attribute_type="gene_id", threads=4,
                  min_mapping_quality=10, ...)
  - Wraps Rsubread::featureCounts()
  - Strandedness read from sample sheet and auto-mapped (unstranded=0,
    forward=1, reverse=2)
  - Writes <sample_id>_counts.txt (gene_id + count TSV)
  - Writes <sample_id>_featurecounts.rds (full result object)

aggregate.R:
------------
HORIZON_aggregate_counts(sample_sheet, output_root=NULL, save_rds=TRUE,
                         save_metadata=TRUE)
  - Reads per-sample _counts.txt files and builds genes x samples matrix
  - Skips samples with missing count files (warning)
  - output_root inferred from first sample if NULL
  - Writes count_matrix.csv, count_matrix.rds, sample_metadata.csv
    to <output_root>/aggregated/counts/

================================================================================
DEPENDENCIES / NOTES
================================================================================
- Rsubread: alignment (align()) + counting (featureCounts()) + index (buildindex())
- Rfastp: QC + trimming (rfastp()) — bundles fastp binary, cross-platform
- Rsamtools: BAM sorting (sortBam()) + indexing (indexBam()) + BAM scanning
- deeptools bamCoverage (external, not an R package) — required by HORIZON_bam_to_bigwig
  Install: conda install -c bioconda deeptools
- samtools (external) — required by HORIZON_rename_chromosomes for BAM files
  Install: conda install -c bioconda samtools
- rtracklayer + GenomeInfoDb (Bioconductor, Suggests) — required by
  HORIZON_rename_chromosomes for BigWig files
  Install: BiocManager::install("rtracklayer")
- All Bioconductor packages: install via BiocManager::install()
- Output directory structure: <output_dir>/<sample_id>/{qc,aligned,counts}/
- Aggregated output: <output_root>/aggregated/counts/
- Functions process one sample at a time by design (RAM-conservative)
- Workflow: devtools::document("HORIZON") then devtools::install("HORIZON")
