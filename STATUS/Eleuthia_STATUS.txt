eleuthia_massspec.R:
--------------------
ELEUTHIA_load_massspec(ms_file, sheet=1, metadata_file=NULL, metadata_sheet=1,
                        sample_col="SampleID", n_annotation_cols=NULL, verbose=TRUE)
  - Reads DIA-NN report.pg_matrix format (.xlsx, .tsv, .txt, .csv)
  - Auto-detects annotation vs sample columns from file-path column names
  - Parses sample ID from Windows/POSIX file paths (strips directory + well suffix)
  - Classifies sample types: SAMPLE (numeric IDs), SEP_SAMPLE, CONTROL, POOL, OTHER
  - Log2-transforms intensities; zeros/negatives become NA
  - Optionally joins metadata file onto sample_meta by sample_col
  - Returns massspec_data S3 object: $wide (log2 matrix), $sample_meta, $protein_meta, $params
print.massspec_data()
  - S3 print method for massspec_data objects

eleuthia_olink.R:
-----------------
ELEUTHIA_load_olink(npx_file, metadata_file=NULL, metadata_sheet=1,
                    sample_col="SampleID", npx_col="NPX",
                    restrict_to_metadata=FALSE, verbose=TRUE)
  - Reads Olink Explore NPX parquet (or CSV); optionally joins plate layout metadata
  - Parses out AssayType!="assay" instrument control rows (structural, not QC filtering)
  - Returns ALL samples as-loaded (biological + controls, all QC statuses)
  - Returns olink_data S3 object: $data (long), $wide (features x samples matrix),
    $sample_meta, $assay_meta (OlinkID + warn_fraction per protein), $params
  - restrict_to_metadata=TRUE: removes NPX samples absent from the metadata file
  - No filtering performed — pass result to HADES_filter_olink() for QC/filtering
  - Requires arrow for .parquet; requires readxl for .xlsx metadata
ELEUTHIA_export_olink_qc(olink_data, assoc, qc_plots, output_dir,
                          top_n_vars=5, p_threshold=0.05,
                          heatmap_top_n=NULL, ntop_pca=NULL, verbose=TRUE)
  - Exports full Olink QC/exploration pipeline outputs to structured directory
  - data/: olink_filtered.rds, sample_meta.csv, assay_meta.csv
  - qc/: npx_distributions.png, sample_qc.csv, warn_proteins.png (if present), summary.txt
  - association/: pc_metadata_heatmap.png (generated internally from assoc)
  - pca/: one PNG per selected variable, using the 2 most significant PCs for that variable
  - top_n_vars controls how many variables per PC are included in the PCA loop

  - Call accessible regions from fragment files
ELEUTHIA_merge_fragments(bed_files, merge_distance, min_fragments, extend, chrom_sizes, ...)
  - Pool fragments from all samples, extend ±extend bp, merge within merge_distance,
    filter by min_fragments; returns candidate regions with n_fragments, n_samples, width
  - n_samples: number of distinct samples that contributed ≥1 fragment to each region
    (tracked during sweep via per-region logical vector — no post-hoc overlap step)
ELEUTHIA_select_regions(candidate_regions, min_fragments, quantile_threshold, max_width, min_samples, by_density, min_density, ...)
  - Filter candidate regions from ELEUTHIA_merge_fragments()
  - Filter order: max_width → min_samples → count/density threshold
  - max_width: hard cap on region width (removes broad, diffuse accumulations)
  - min_samples: require ≥N samples to have contributed fragments (cross-sample consistency)
    quantile computed AFTER min_samples filter — prevents low-support regions diluting distribution
  - by_density=TRUE: filters on n_fragments/width (fragments per bp) instead of raw count
  - Always outputs fragment_density and n_samples columns for inspection
  - Default (by_density=FALSE, no min_samples, no max_width) is fully backward-compatible
ELEUTHIA_quantify_bed(sample_sheet, regions, omics, ...)
  - Quantify fragment overlaps from BED files against a set of regions
