artemis_bw_quantification.R:
-----------------------------
ARTEMIS_load_bw_coverage(sample_sheet, sample_col="sample_id", bw_col="bw_path")
  - Reads all BigWig files in a sample sheet once; returns artemis_bw_coverage object
  - $coverage: named list of RleList objects (one per sample)
  - $bw_chrnames: chromosome names from the first BigWig (for harmonization)
  - Pass to ARTEMIS_prepare_bw_comparison(coverage=...) to skip re-reading files
  - Use when the same samples are queried over many region sets (e.g. feature loop)

ARTEMIS_prepare_bw_comparison(sample_sheet, group_x, group_y, regions,
  bin_size=1000, genome=NULL, ratio=FALSE, pseudocount=1, min_signal=NULL,
  sample_col="sample_id", bw_col="bw_path", coverage=NULL)
  - Prepares two-column data frame for AETHER_plot_density_scatter
  - Extracts mean BigWig signal over genomic regions (bins/BED/GRanges)
  - group_x/group_y: named lists; 1-name = direct mean, 2-name+ratio=TRUE = log2 ratio
  - Position-based denominator/numerator: first name = denominator, second = numerator
  - Replicate handling: element-wise mean across samples per group
  - min_signal: removes regions where BOTH axis representatives < threshold
  - log2 ratio computed AFTER min_signal filter, using pseudocount
  - coverage: optional artemis_bw_coverage from ARTEMIS_load_bw_coverage(); when
    provided, BigWig files are not re-read — signal extracted from pre-loaded RLEs
  - Returns data.frame(x, y, chr, start, end) with attr x_label/y_label

artemis_limma.R:
-----------------
ARTEMIS_limma_de(matrix, sample_meta, group_col, reference, experiment,
                 sample_col=NULL, covariates=NULL, block_col=NULL,
                 feature_meta=NULL, feature_id_col=NULL, fdr=0.05, lfc=0, verbose=TRUE)
  - Linear model DE for any log2-scale matrix (Olink NPX, log2 mass spec, microarray)
  - Do NOT use for count-based data (RNA-seq, ATAC-seq) — use ARTEMIS_differential_counts()
  - block_col: repeated measures via limma::duplicateCorrelation() (e.g. SubjectID for
    longitudinal Olink data)
  - feature_meta: joined onto results; matched first by rownames, then by column value
  - feature_id_col: column in feature_meta to use as feature_id (e.g. "Assay" for Olink
    gene symbols); original matrix rownames retained as original_id
  - Returns artemis_limma S3 object:
    $results (feature_id, [original_id], logFC, AveExpr, t, P.Value, adj.P.Val, B, sig),
    $fit (MArrayLM), $summary, $comparison, $norm_matrix, $params
  - sig = adj.P.Val < fdr & |logFC| >= lfc; all features retained for ORA background
  - Requires limma (Suggests)

artemis_pca_qc.R:
------------------
ARTEMIS_pc_metadata_association(matrix, sample_meta, n_pcs=10, ntop=NULL,
                                 sample_col=NULL, metadata_cols=NULL,
                                 scale=TRUE, categorical_threshold=10, verbose=TRUE)
  - Tests PC-metadata associations on any log2-scale matrix
  - ntop=NULL uses all features; ntop=N selects top N most variable features for PCA
  - Categorical variables (<=categorical_threshold unique values): Kruskal-Wallis + eta-sq
  - Continuous variables: Spearman correlation + rho
  - Returns artemis_pc_assoc S3: $pvalues, $effect_sizes, $test_used,
    $var_explained, $pca, $params

artemis_atac_annotation.R:
---------------------------
ARTEMIS_compare_annotation_distribution(annotated_list, metadata,
  group_col="group", feature_col="annotation_simple",
  method="wilcoxon", p_adj_method="BH", verbose=TRUE)
  - Compares peak annotation proportions between exactly 2 groups
  - Per-sample peak counts computed from annotated data.frames (APOLLO_annotate_peaks output)
  - Wilcoxon rank-sum or t-test per feature; BH correction across features
  - Note: tests raw counts; valid when peak libraries are balanced within batch
    (e.g., spike-in normalization)
  - Returns list: $results (feature stats), $counts (long df), $groups,
    $group_col, $feature_col, $method
  - Use AETHER_plot_annotation_comparison() to visualise

artemis_consensus_clustering.R:
---------------------------------
ARTEMIS_consensus_cluster(imputed_obj, vars=NULL, log_vars=NULL, scale_data=TRUE,
                           k_max=10, n_resample=100, resample_prop=0.8,
                           clusterAlg="km", distance="euclidean", seed=42, verbose=TRUE)
  - Runs ConsensusClusterPlus on each imputed dataset (from POSEIDON_mice_impute),
    averages consensus matrices across all imputations
  - Accounts for imputation uncertainty; follows Oslo sepsis clustering approach
    (Wick et al. 2024: 100 imputations, averaged matrices)
  - Returns artemis_cc S3 object: $consensus_matrices, $cluster_assignments,
    $wcss, $cdf_area, $delta_area, $cdf_values, $scaled_mean_data (and metadata)
  - Requires ConsensusClusterPlus (soft dep, BiocManager::install)

ARTEMIS_consensus_stability(imputed_obj, k, n_runs=10, vars=NULL, log_vars=NULL,
                             scale_data=TRUE, n_resample=100, resample_prop=0.8,
                             clusterAlg="km", imputation_idx=1, seed=42, verbose=TRUE)
  - Runs CC n_runs times on one imputed dataset (random restart) to test stability
  - Returns $assignment_matrix (patients × runs), $stability_counts, $pct_stable
  - Use after ARTEMIS_consensus_cluster to assess stability of chosen k

artemis_part_clustering.R:
---------------------------
ARTEMIS_part(expr_matrix, ...)
  - PART (Partition Around medoids for Time series) clustering
  - Requires a complete matrix (no NA) -- Gap statistic's ref_gen="PC" needs
    svd() on the full matrix. Fails fast with an explanatory stop() if mat
    contains NA, instead of the cryptic "infinite or missing values in 'x'"
    error from svd() (added 2026-06-23, surfaced by mass-spec proteomics
    data, which has real missingness). Caller must impute deliberately
    beforehand if clustering data with missingness.
ARTEMIS_part_summary(part_result, ...)
  - Summary statistics for PART clustering result

artemis_timeseries_analysis.R:
--------------------------------
--- DESeq2 workflow (count data: RNA-seq, ATAC-seq) ---
ARTEMIS_normalize_timeseries(counts, targets, group_col, time_col, batch_col, verbose)
  - Normalize full count matrix via DESeq2 size factors (MUST run first)
  - Returns artemis_ts_norm; pass to conditional/temporal functions
ARTEMIS_timeseries_conditional(ts_norm, reference, experiment, alpha, verbose)
  - Compare two groups at each timepoint using pre-computed size factors
  - Returns artemis_ts_de
ARTEMIS_timeseries_temporal(ts_norm, comparisons, alpha, verbose)
  - Compare consecutive/all timepoints (groups pooled) using pre-computed size factors
  - Returns artemis_ts_de

--- limma workflow (log2-scale data: Olink NPX, log2 mass spec, microarray) ---
ARTEMIS_normalize_timeseries_limma(matrix, targets, group_col, time_col, batch_col, verbose)
  - Validates and stores log2-scale matrix; no transformation applied
  - batch_col auto-prepended to covariates in downstream comparison functions
  - Warns if matrix looks like raw counts
  - Returns artemis_ts_norm_limma
ARTEMIS_timeseries_conditional_limma(ts_norm, reference, experiment, block_col,
                                      covariates, alpha, verbose)
  - Compare two groups at each timepoint using limma linear models
  - block_col: repeated measures via duplicateCorrelation (e.g. crossover design)
  - Returns artemis_ts_de (same class as DESeq2 version for downstream compatibility)
ARTEMIS_timeseries_temporal_limma(ts_norm, comparisons, block_col, covariates,
                                   alpha, verbose)
  - Compare consecutive/all timepoints (groups pooled) using limma
  - block_col: paired design (e.g. SubjectID when same subjects measured at each TP)
  - Returns artemis_ts_de
