artemis_limma.R:
-----------------
ARTEMIS_limma_de(matrix, sample_meta, group_col, reference, experiment,
                 sample_col=NULL, covariates=NULL, block_col=NULL,
                 feature_meta=NULL, feature_id_col=NULL, fdr=0.05, lfc=0, verbose=TRUE)
  - Linear model DE for any log2-scale matrix (Olink NPX, log2 mass spec, microarray)
  - Do NOT use for count-based data (RNA-seq, ATAC-seq) — use ARTEMIS_differential_counts()
  - block_col: repeated measures via limma::duplicateCorrelation() (e.g. SubjectID for
    longitudinal Olink data)
  - feature_meta: joined onto results; matched first by rownames, then by column value
  - feature_id_col: column in feature_meta to use as feature_id (e.g. "Assay" for Olink
    gene symbols); original matrix rownames retained as original_id
  - Returns artemis_limma S3 object:
    $results (feature_id, [original_id], logFC, AveExpr, t, P.Value, adj.P.Val, B, sig),
    $fit (MArrayLM), $summary, $comparison, $norm_matrix, $params
  - sig = adj.P.Val < fdr & |logFC| >= lfc; all features retained for ORA background
  - Requires limma (Suggests)

artemis_pca_qc.R:
------------------
ARTEMIS_pc_metadata_association(matrix, sample_meta, n_pcs=10, ntop=NULL,
                                 sample_col=NULL, metadata_cols=NULL,
                                 scale=TRUE, categorical_threshold=10, verbose=TRUE)
  - Tests PC-metadata associations on any log2-scale matrix
  - ntop=NULL uses all features; ntop=N selects top N most variable features for PCA
  - Categorical variables (<=categorical_threshold unique values): Kruskal-Wallis + eta-sq
  - Continuous variables: Spearman correlation + rho
  - Returns artemis_pc_assoc S3: $pvalues, $effect_sizes, $test_used,
    $var_explained, $pca, $params

artemis_atac_annotation.R:
---------------------------
ARTEMIS_compare_annotation_distribution(annotated_list, metadata,
  group_col="group", feature_col="annotation_simple",
  method="wilcoxon", p_adj_method="BH", verbose=TRUE)
  - Compares peak annotation proportions between exactly 2 groups
  - Per-sample peak counts computed from annotated data.frames (APOLLO_annotate_peaks output)
  - Wilcoxon rank-sum or t-test per feature; BH correction across features
  - Note: tests raw counts; valid when peak libraries are balanced within batch
    (e.g., spike-in normalization)
  - Returns list: $results (feature stats), $counts (long df), $groups,
    $group_col, $feature_col, $method
  - Use AETHER_plot_annotation_comparison() to visualise

artemis_consensus_clustering.R:
---------------------------------
ARTEMIS_consensus_cluster(imputed_obj, vars=NULL, log_vars=NULL, scale_data=TRUE,
                           k_max=10, n_resample=100, resample_prop=0.8,
                           clusterAlg="km", distance="euclidean", seed=42, verbose=TRUE)
  - Runs ConsensusClusterPlus on each imputed dataset (from POSEIDON_mice_impute),
    averages consensus matrices across all imputations
  - Accounts for imputation uncertainty; follows Oslo sepsis clustering approach
    (Wick et al. 2024: 100 imputations, averaged matrices)
  - Returns artemis_cc S3 object: $consensus_matrices, $cluster_assignments,
    $wcss, $cdf_area, $delta_area, $cdf_values, $scaled_mean_data (and metadata)
  - Requires ConsensusClusterPlus (soft dep, BiocManager::install)

ARTEMIS_consensus_stability(imputed_obj, k, n_runs=10, vars=NULL, log_vars=NULL,
                             scale_data=TRUE, n_resample=100, resample_prop=0.8,
                             clusterAlg="km", imputation_idx=1, seed=42, verbose=TRUE)
  - Runs CC n_runs times on one imputed dataset (random restart) to test stability
  - Returns $assignment_matrix (patients × runs), $stability_counts, $pct_stable
  - Use after ARTEMIS_consensus_cluster to assess stability of chosen k
