poseidon_preprocessing.R:
--------------------------
POSEIDON_scale_data(X, ...)
  - Scale data (centering, unit variance, or 0-1 normalization)
POSEIDON_filter_zero_variance(X_list, ...)
  - Remove zero-variance features from dataset list
POSEIDON_filter_shared_variance(X_list, by_row, ...)
  - Filter features by shared variance across datasets
POSEIDON_validate_multi_dataset(X_list, ...)
  - Validate sample alignment across multiple omics datasets
POSEIDON_filter_low_counts(counts, ...)
  - Filter low count genes (count-based; complements Eleuthia loader)
POSEIDON_plot_batch_pca(counts, sample_sheet, ...)
  - PCA plot coloured by batch for visual batch effect assessment
POSEIDON_normalize_massspec(wide, verbose=TRUE)
  - Per-sample median centering for log2-scale DIA mass spectrometry matrices
  - Subtracts per-sample median (non-NA values) to remove run-to-run intensity shifts
  - Takes a proteins x samples matrix; returns the same dimensions
  - Use: ms$wide <- POSEIDON_normalize_massspec(ms$wide)

POSEIDON_mice_impute(data, n_imputations=100, method="pmm", max_iter=20,
                     log_vars=NULL, seed=42, verbose=TRUE)
  - Multiple imputation by chained equations (MICE) for clinical/mixed numeric data
  - log_vars: columns log1p-transformed before imputation, back-transformed in output
  - Returns: $datasets (list of n completed data frames), $mean_dataset (column-wise
    average across imputations for centroid computation), $log_vars, $n_imputations
  - Intended as input to ARTEMIS_consensus_cluster()
  - Requires mice package (soft dep: install.packages("mice"))
