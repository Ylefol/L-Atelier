assumed) used to prepare features for integration methods like sCCA.

poseidon_batch_correction.R:
------------------------------
POSEIDON_correct_batch_counts(quant_result, batch_col="batch", group_col="group",
                               method="combat", log_transform=TRUE, ...)
  - Batch correction via ComBat (sva) or limma::removeBatchEffect
  - Operates on quant_result ($counts numeric matrix); optionally preserves a
    biological group column as a covariate via model.matrix
  - Renamed from POSEIDON_correct_batch() (2026-06-19) once a second,
    massspec-specific function was added - no backwards-compatibility shim,
    callers (e.g. projects/SMUG1_lisa/process_data.R) need updating on next run
POSEIDON_correct_batch_massspec(massspec_data, batch_col="PlateID", group_col=NULL,
                                 method="combat", impute_method="batchmean", verbose=TRUE)
  - Batch correction via ComBat or limma::removeBatchEffect for massspec_data
    objects ($wide log2 matrix + $sample_meta)
  - Unlike the counts version: no log2(x+1)/back-transform (data is already
    log2), and NAs are handled via a disposable imputed working copy used
    only to make ComBat/limma runnable - corrected values are written back
    only at originally non-NA cells, real NAs stay NA
  - impute_method controls how that disposable working copy is filled:
    "batchmean" (default) imputes each protein's mean WITHIN its own batch
    (observed cells only, falling back to the global mean if a protein has
    zero observed values in a batch); "global" imputes the protein's mean
    across all samples (the original behavior). Comparison on the SEPSOMICS
    dataset (projects/SEPSOMICS/massSpec_imputation_comparison.R, 2026-06-22)
    showed "global" under-corrects high-missingness proteins (mean
    between-batch variance removed: 84.1% vs 99.5% for "batchmean"; gap grows
    with missingness, Spearman rho=0.95) - "global" kept as an explicit
    option since this was only verified on one dataset/filtering setup
  - group_col NA values (e.g. POOL samples with no biological group) get
    their own "no_group" factor level rather than being dropped
POSEIDON_plot_batch_pca(quant_result, batch_col="batch", group_col="group", ...)
  - PCA scatter colored by batch, shaped by group, for before/after comparison
  - Note: this is a plotting function under a POSEIDON_ prefix rather than
    AETHER_ - flagged as a naming/placement inconsistency, not yet resolved

poseidon_normalization.R:
------------------------------
POSEIDON_normalize_massspec(wide, method=c("vsn","median_centering"), verbose=TRUE)
  - Normalizes log2-scale DIA mass spectrometry matrix
  - method="vsn" (default): back-transforms 2^wide, fits vsn::justvsn() per sample
    (robust glog/arsinh calibration), restores original NA positions. Corrects both
    cross-sample location shifts AND heteroscedasticity (variance instability across
    intensity range). Requires vsn (BiocManager::install("vsn")).
  - method="median_centering": subtracts per-sample median on log2 scale; lightweight
    fallback, no heteroscedasticity correction
  - Takes a proteins x samples matrix; returns the same dimensions
  - Use: ms$wide <- POSEIDON_normalize_massspec(ms$wide)

poseidon_imputation.R:
------------------------------
POSEIDON_impute_massspec(massspec_data, verbose=TRUE)
  - QRILC imputation for massspec_data objects (Lazar et al. 2016)
  - MNAR-appropriate: assumes missing = below instrument detection limit;
    fits quantile regression per sample to estimate the left-censored tail,
    draws imputed values from that estimated distribution
  - Call AFTER normalization and batch correction (imputed values land on the
    final processed scale)
  - Stores original NA positions in massspec_data$na_mask (logical matrix,
    same dims as $wide) so real vs imputed values remain distinguishable
  - Updates massspec_data$wide to a fully NA-free matrix
  - Records method/counts in massspec_data$params$imputation
  - Requires imputeLCMD (install.packages("imputeLCMD"); or
    remotes::install_github("cran/imputeLCMD") if archived from CRAN)

POSEIDON_mice_impute(data, n_imputations=100, method="pmm", max_iter=20,
                     log_vars=NULL, seed=42, verbose=TRUE)
  - Multiple imputation by chained equations (MICE) for clinical/mixed numeric data
  - log_vars: columns log1p-transformed before imputation, back-transformed in output
  - Returns: $datasets (list of n completed data frames), $mean_dataset (column-wise
    average across imputations for centroid computation), $log_vars, $n_imputations
  - Intended as input to ARTEMIS_consensus_cluster()
  - Requires mice package (soft dep: install.packages("mice"))
