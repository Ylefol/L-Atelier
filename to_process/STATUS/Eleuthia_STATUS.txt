eleuthia_data_import.R:
-----------------------
ELEUTHIA_load_counts_from_dir(count_path, ...)
  - Load count files from a directory
ELEUTHIA_load_multi_counts(count_paths, ...)
  - Load and combine counts from multiple paths/datasets

eleuthia_atac_export.R:
-----------------------
ELEUTHIA_export_atac_results(output_dir, ...)
  - Orchestrating export for full ATAC-seq pipeline results
  - Delegates annotated_peaks → CSV, dea_result → export_dea_results,
    enrichment → export_enrichment, homer_result → export_homer_results,
    sequence_composition → export_sequence_composition

eleuthia_composition_export.R:
-------------------------------
ELEUTHIA_export_sequence_composition(composition, output_dir, ...)
  - Export APOLLO_sequence_composition() data.frame
  - Composition CSV (no sequence col), optional sequences CSV, summary TXT

eleuthia_dea_export.R:
-----------------------
ELEUTHIA_export_dea_results(dea_result, output_dir, ...)
  - Export differential analysis results to files
  - Now includes volcano and MA plots when save_plots = TRUE
