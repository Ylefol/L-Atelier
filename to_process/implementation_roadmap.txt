================================================================================
1. NanostringR
================================================================================
Status: PLANNED
Source: https://github.com/Ylefol/NanostringR (user's package)
Reference: Existing R package to port/integrate

Overview:
Compendium of Nanostring-related tools. Simpler scope:
- Quality control for Nanostring data
- Differential expression analysis

Key Components to Implement:

A) Data Import
   GAIA Module: Eleuthia
   Functions:
   [ ] ELEUTHIA_load_nanostring() - import Nanostring data formats
   [ ] ELEUTHIA_nanostring_metadata() - parse sample metadata

B) Quality Control
   GAIA Module: Hades
   Functions:
   [ ] HADES_nanostring_qc() - Nanostring-specific QC metrics
   [ ] HADES_nanostring_normalize() - or Poseidon? (normalization)

C) Normalization (if separate from QC)
   GAIA Module: Poseidon
   Functions:
   [ ] POSEIDON_nanostring_normalize() - Nanostring normalization methods

D) Differential Expression
   GAIA Module: Artemis
   Functions:
   [ ] ARTEMIS_nanostring_dea() - or use general ARTEMIS_dea()

E) Visualization
   GAIA Module: Aether
   Functions:
   [ ] AETHER_plot_nanostring_qc() - QC plots

Notes:
- Consider whether Nanostring DEA should be separate or use general DEA functions
- Nanostring has specific normalization requirements (housekeeping genes, etc.)

================================================================================
NOTES / DECISIONS LOG
================================================================================
2026-02-03: Created roadmap
- WGCNA enrichment switched from clusterProfiler to gprofiler2
- TiSA PART clustering prioritized as standalone component
- immunedeconv preferred over direct CIBERSORT (licensing)

2026-02-03: Adjusted priority order
- Moved immunedeconv to #2, DecoupleR to #3
- TiSA (#4) and NanostringR (#5) are standalone pipelines that can run separately
- immunedeconv/DecoupleR benefit more from ZERO_DAWN integration

2026-02-05: TiSA implemented
- PART clustering ported from clusterGenomics (Nilsen et al. 2013) to Artemis
- PART is standalone (usable outside time series context)
- Time series DEA wraps existing ARTEMIS_differential_counts()
- Visualization: heatmap, trajectories, cluster means, DEA summary
- Export follows ELEUTHIA_export_wgcna_results/activity_results pattern

2026-02-03: Switched from immunedeconv to CIBERSORT
- CIBERSORT chosen over immunedeconv/CIBERSORTx/EcoTyper
- Rationale: Gold standard, versatile (any tissue), simpler output, easy to justify
- LM22 for immune, can use custom signatures for other cell types
- Academic source code access (registration at cibersortx.stanford.edu)
- EcoTyper may be added later for cell state resolution in TME if needed
