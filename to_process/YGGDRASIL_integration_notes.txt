Created: 2026-02-23

================================================================================
OVERVIEW
================================================================================
YGGDRASIL is a separate R package toolkit for single-cell and single-nuclei
RNA-seq analysis, designed as a companion to GAIA (bulk multi-omics). It
follows the same architectural philosophy: a central orchestrating system with
named subordinate modules, each handling a specific stage of the analysis
workflow.

Primary scope: scRNA-seq and snRNA-seq
Future expansion: scATAC-seq, multiome (snRNA + snATAC), spatial transcriptomics

Relationship to GAIA:
- Separate R package (not integrated into GAIA)
- Fully independent — no formal GAIA imports
- Targeted code reuse addressed case-by-case (selective import or copy)
- Installed independently via devtools::install("YGGDRASIL")
- Same naming and documentation conventions as GAIA

================================================================================
NAMING CONVENTION
================================================================================
Theme: Norse mythology (public domain)
Method: Old Norse spellings, no special/Icelandic characters (ð, þ, ö, æ, etc.)

Central system: YGGDRASIL (Yggdrasill)
  The world tree connecting all nine realms — orchestrates all modules.

All functions follow the strict prefix convention: MODULE_function_name
  e.g., HEL_filter_cells(), MIMIR_annotate_singler(), BALDR_plot_umap()

+------------+-------------+-----------------------------------------------+

|            | (Bifröst)   | format conversion; report generation          |
+------------+-------------+-----------------------------------------------+

|            |             | adaptive filtering                            |

|            | (Njörðr)    | SCTransform); HVG selection; scaling;        |
|            |             | cell cycle regression; batch correction      |
|            |             | (Harmony, etc.)                              |
+------------+-------------+-----------------------------------------------+
| Embedding  | SLEIPNIR    | PCA, UMAP, tSNE; graph construction          |
|            | (Sleipnir)  | (KNN/SNN); clustering (Leiden/Louvain);      |
|            |             | resolution tuning                             |
+------------+-------------+-----------------------------------------------+
| Annotation | MIMIR       | Marker-based annotation; reference-based     |
|            | (Mímir)     | annotation (SingleR, Azimuth); cell type     |
|            |             | hierarchy; manual label management           |
+------------+-------------+-----------------------------------------------+
| Expression | TYR         | Cluster markers; condition DE; pseudobulk    |
|            | (Týr)       | DE; gene set enrichment (GSEA/ORA)           |
+------------+-------------+-----------------------------------------------+
| Dynamics   | NORNIR      | Pseudotime (Monocle3); RNA velocity;         |
|            | (Nornir)    | CytoTRACE (stemness); trajectory/lineage     |
|            |             | inference; cell-cell communication           |
|            |             | (CellChat, NicheNet, LIANA)                  |
|            |             | NOTE: May split Trajectory and Communication |
|            |             | into separate modules as scope grows         |
+------------+-------------+-----------------------------------------------+

|            | (Baldr)     | feature plots; heatmaps; trajectory plots;   |
|            |             | communication network plots                  |
+------------+-------------+-----------------------------------------------+
| Utilities  | FREYR       | Shared helpers; object manipulation;         |
|            | (Freyr)     | configuration; common data structures        |
|            |             | Parallel to GAIA's DEMETER module            |
+------------+-------------+-----------------------------------------------+

Data flow:
BIFROST → HEL → NJORD → SLEIPNIR → MIMIR → TYR / NORNIR → BALDR → BIFROST

BIFROST  - The rainbow bridge, gateway between worlds. Data enters and exits
           the toolkit through it.
HEL      - Ruler of the dead realm. Separates the living from the dead —
           filtering dead cells, doublets, ambient RNA.
NJORD    - God of the sea. Cleansing and purifying — normalization, batch
           effect removal, washing away technical noise.
SLEIPNIR - Odin's eight-legged horse, the only being able to traverse between
           all realms. Dimensional reduction maps data across representational
           spaces.
MIMIR    - Keeper of the well of wisdom (Mímisbrunnr). The oracle who knows
           what everything is — cell type annotation.
TYR      - God of law and just judgment. Statistical testing demands fair,
           principled comparison.
NORNIR   - The three fates (Urd, Verdandi, Skuld — past, present, future).
           Masters of time and destiny — pseudotime, trajectory, communication.
BALDR    - God of light and beauty. Makes the invisible visible.
FREYR    - God of fertility, harvest, and prosperity. Nourishes all other
           modules. Direct parallel to Demeter (GAIA's DEMETER module).

================================================================================
IMPLEMENTATION NOTES
================================================================================
Primary object: SingleCellExperiment (Bioconductor)
  Rationale:
  - Modular and programmatically flexible — better foundation for a custom toolkit
  - Native integration with scran, scDblFinder, SingleR, MAST, edgeR/DESeq2
  - Structural near-equivalence with AnnData (obs→colData, var→rowData,
    obsm→reducedDims, obsp→colPairs, uns→metadata, layers→assays)
    making Scanpy/Python experience directly transferable
  - h5ad/loom legacy data handled cleanly via zellkonverter and LoomExperiment
  - Bioconductor's strict deprecation policy insulates against breaking changes
    (cf. Seurat v5 disruption)
  - Seurat compatibility handled via BIFROST conversion functions as needed;
    no full Seurat dependency

Primary R ecosystem targets:
  - SingleCellExperiment, SummarizedExperiment (core object)
  - scran, scater (normalization, QC)
  - scDblFinder (doublet detection)
  - SoupX / decontX (ambient RNA)
  - SingleR (reference-based annotation)
  - Monocle3 (trajectory/pseudotime)
  - zellkonverter (AnnData/h5ad interop)
  - Seurat (conversion only, not a hard dependency)
  - ArchR (future scATAC expansion)

- devtools::document() + devtools::install() workflow same as GAIA
- No source() calls — all inter-module access via package namespace
