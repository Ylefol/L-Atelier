pyri_preprocessing.R:
---------------------
PYRI_normalize(sce, method="lognorm", assay_name="counts", verbose=TRUE)
  - method="lognorm": library-size normalization + log1p via scater::logNormCounts
  - method="scran": pooling-based size factors via scran::quickCluster +
    scran::computeSumFactors, then scater::logNormCounts
  - Both produce "logcounts" assay; scran also stores sizeFactors(sce)
  - Prints size factor range and median

PYRI_select_hvg(sce, n_hvgs=2000, block_col=NULL, assay_name="logcounts",
                 verbose=TRUE)
  - Models mean-variance relationship via scran::modelGeneVar
  - BPCells-aware: if logcounts is a BPCells IterableMatrix, uses
    BPCells::matrix_stats() (streaming) + scran::fitTrendVar() to extract
    biological variance without loading the full matrix into RAM;
    scran::modelGeneVar bypassed (beachmat incompatibility)
  - Blocking with BPCells: fits trend per block and averages bio component
  - block_col: colData column for per-sample blocking (strongly recommended
    for multi-sample datasets — prevents depth differences driving selection)
  - Selects top n_hvgs by biological variance
  - Stores results in:
      rowData(sce)$is_hvg  — logical flag per gene
      metadata(sce)$hvg    — character vector of HVG names (used by TALOS)
  - Requires PYRI_normalize() to have been run first
