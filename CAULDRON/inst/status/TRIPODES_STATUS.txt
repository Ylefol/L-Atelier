DEPENDENCIES / NOTES
================================================================================
- Key packages: monocle3, velociraptor (R interface to scVelo), CytoTRACE
- Requires annotated, embedded data (TALOS + PANDORA) before trajectory
  inference is meaningful
- RNA velocity requires spliced/unspliced count matrices — these must be
  generated at the alignment stage (STARsolo, alevin-fry) and loaded via
  TALARIA
- TRIPODES was split from the original combined Dynamics module to separate
  trajectory inference from cell-cell communication (now DIKTYON)
