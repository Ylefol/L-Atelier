TRIPODES_check_velocity_ready(sce, spliced_assay="spliced", unspliced_assay="unspliced", verbose=TRUE)
  - Fast, non-destructive SCE validation before running RNA velocity
  - Detects alternate naming conventions (Ms/Mu = scVelo moments, not raw counts;
    counts_spliced/counts_unspliced) and advises renaming
  - Hard errors (block pipeline): missing assays, dimension mismatch, continuous data
  - Soft warnings (inform only, do not block): unusual splicing ratio, low unspliced UMI
    Low splicing ratio (~20% spliced) expected for Parse Biosciences random hexamer priming
  - Reports: n_cells, n_genes, median spliced/unspliced UMI, global splicing ratio
  - Returns invisibly: named list ($ready, $spliced_assay, $unspliced_assay, $n_cells,
    $n_genes, $median_spliced, $median_unspliced, $splicing_ratio, $issues, $warnings)

TRIPODES_assess_splicing(sce, spliced_assay="spliced", unspliced_assay="unspliced",
                          min_unspliced_mean=0.01, ratio_range=c(0.05, 0.99), verbose=TRUE)
  - Detailed per-cell and per-gene splicing QC; run after check_velocity_ready
  - Per-cell metrics added to colData: splicing_ratio, total_spliced, total_unspliced
  - Per-gene metrics added to rowData: mean_spliced, mean_unspliced,
    gene_splicing_ratio, velocity_reliable (logical flag)
  - velocity_reliable=TRUE: mean_unspliced >= min_unspliced_mean AND
    gene_splicing_ratio within ratio_range (genes with extreme ratios unreliable)
  - Reports: median cell splicing ratio, % cells with <10% spliced,
    n velocity-reliable genes; warns if <20% genes are reliable
  - Sets metadata(sce)$splicing_assessed = TRUE
  - Returns modified SCE; data consumed by ASPIS_plot_splicing (not yet implemented)
  - BPCells-aware (uses matrix_stats for col/row means)

TRIPODES_run_velocity(sce, spliced_assay="spliced", unspliced_assay="unspliced",
                       mode="deterministic", use_dimred="PCA", n_pcs=30L,
                       n_neighbors=30L, verbose=TRUE)
  - RNA velocity via CAULDRON-managed Python env + inst/python/scvelo_run.py
  - NO velociraptor dependency — scVelo called directly via basilisk
  - Basilisk env: .cauldron_scvelo_env (Python 3.12, scvelo==0.3.3, numpy==2.2.5,
    scanpy==1.11.1, anndata==0.11.4, scipy==1.15.2, matplotlib==3.10.1,
    legacy-api-wrap==1.4.1)
  - All three modes confirmed working: deterministic (default), stochastic, dynamical
  - use_dimred="PCA": PCA coords passed to Python so scVelo neighbour graph is
    consistent with UMAP embedding; n_pcs auto-capped to available components
  - Warns (does not error) if TRIPODES_assess_splicing not yet run
  - Subsets to velocity_reliable genes before running (avoids degenerate matrices)
  - Coerces spliced/unspliced to dgCMatrix float (read-only reticulate memory issue
    resolved by explicit .data/.indices/.indptr copy in Python before in-place ops)
  - sc.pp.neighbors called explicitly before scv.pp.moments (scVelo 0.3.x deprecation)
  - UMAP and TSNE coords also passed if present; velocity projected onto all embeddings
  - Stored in SCE:
      assay "velocity"         — full gene space; non-reliable genes = NA
      colData $velocity_confidence, $velocity_length
      reducedDim "velocity_PCA"  (if PCA present)
      reducedDim "velocity_UMAP" (if UMAP present at run time)
      reducedDim "velocity_tSNE" (if tSNE present at run time)
  - Sets metadata(sce)$velocity_run=TRUE, metadata(sce)$velocity_mode=mode

ASPIS_plot_velocity_stream(sce, dimred="UMAP", colour_by="cluster", grid_res=30,
                            n_streams=200, stream_length=50, stream_colour="black",
                            stream_size=0.4, stream_alpha=0.8, bandwidth=NULL,
                            min_density=0.05, blob_alpha=0.25, blob_bins=4,
                            show_points=FALSE, point_size=0.3, point_alpha=0.3,
                            min_vel_frac=0.05, palette=NULL, assay_name="logcounts",
                            title=NULL)
  - KDE blob background per cluster (stat_density_2d polygon, one layer per cluster)
  - Streamlines via Gaussian-weighted velocity field on regular grid + Euler integration
  - stream_colour="black": fixed colour; NULL: each streamline coloured by nearest cell cluster
  - Requires discrete colour_by (errors on continuous)
  - min_density: masks grid points below this fraction of peak local cell density (both
    has_vel AND the dx/dy vectors themselves) so streamlines terminate at the edge of real
    data support instead of extrapolating through empty space. Fixed 2026-07-17: the
    Gaussian kernel's infinite support meant the old epsilon-only threshold passed at
    nearly every grid point (even empty corners of a non-convex embedding), producing
    streamlines that wandered through white space disconnected from any cell cluster.

tripodes_cytotrace.R:
---------------------
TRIPODES_score_cytotrace_v1(sce, assay_name="logcounts", n_top_genes=200L,
                              n_neighbours=10L, use_dimred="PCA", n_pcs=30L,
                              recompute_graph=FALSE, score_col="cytotrace_v1",
                              verbose=TRUE)
  - Pure R CytoTRACE v1 algorithm (Gulati et al. 2020)
  - Stemness score per cell: 1 = stem-like / undifferentiated, 0 = differentiated
  - Step 1: gene diversity per cell (colSums > 0)
  - Step 2: Spearman correlation of each gene vs gene diversity (matrixStats::rowRanks,
    vectorised Pearson-of-ranks — no transpose of full matrix required)
  - Step 3: top n_top_genes by |correlation|
  - Step 4: raw score = mean expression of top genes per cell
  - Step 5: neighbourhood smoothing
      Default: reuses metadata(sce)$snn_graph from TALOS_build_graph()
               (row-normalised adjacency matrix × raw scores)
      Fallback: builds fresh kNN via BiocNeighbors::findKNN() if no graph found
               or recompute_graph=TRUE (prominent warning issued when forced)
  - Step 6: normalise [0,1] + invert
  - BPCells-aware: materialises IterableMatrix with clear message before computation
  - Stored: colData(sce)[[score_col]], metadata(sce)$cytotrace_v1_run=TRUE,
    metadata(sce)$cytotrace_v1_col
  - CytoTRACE v2 deferred (requires Python/basilisk)
  - Score can be plotted immediately via ASPIS_plot_umap(colour_by="cytotrace_v1")

TRIPODES_run_monocle(sce, root_cells=NULL, root_cluster=NULL,
                      root_by_cytotrace=FALSE, cytotrace_top_pct=5,
                      cytotrace_col="cytotrace_v1", cluster_col="cluster",
                      use_dimred="UMAP", use_partition=TRUE, close_loop=FALSE,
                      pseudotime_col="monocle_pseudotime", branch_col="monocle_branch",
                      verbose=TRUE)
  - Monocle3 trajectory inference; re-uses pre-computed CAULDRON embedding
  - Exactly one root mode must be active: root_cells (barcodes), root_cluster
    (TALOS cluster label), or root_by_cytotrace (top N% by CytoTRACE score)
  - Bypasses monocle3::preprocess_cds() — injects embedding directly into
    reducedDims(cds); cluster_cells() runs on injected embedding for partitions
  - Monocle3 partitions ≠ TALOS clusters; root_cluster uses TALOS labels
  - Inf pseudotime (cells in rootless partitions) converted to NA
  - BPCells counts materialised to dgCMatrix before new_cell_data_set()
  - Stored: colData $monocle_pseudotime, $monocle_branch;
    metadata $monocle_run, $monocle_graph (igraph), $monocle_graph_nodes
    (node coords in embedding space, nodes×2), $monocle_dimred
