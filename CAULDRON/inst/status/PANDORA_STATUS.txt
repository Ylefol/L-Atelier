pandora_annotation.R:
---------------------
PANDORA_convert_orthologs(genes, from="human", to, method="homologene",
                           drop_na=FALSE, verbose=TRUE)
  - Converts a character vector of gene symbols to orthologs via orthogene
  - Returns a named character vector: names = input symbols, values = ortholog
    symbols (or NA for unmapped genes when drop_na=FALSE)
  - drop_na=FALSE (default): output same length as input, NA for unmapped
  - drop_na=TRUE: unmapped genes dropped; used internally by PANDORA_annotate_sctype
  - Requires orthogene (Suggests)
  - Note: .pandora_convert_sctype_markers now delegates to this function

PANDORA_list_references(source="all", db=NULL)
  - Prints formatted table of available SingleR/celldex reference shorthands
    and scType tissue types from the bundled ScTypeDB
  - source: "all" | "singler" | "sctype"
  - db: NULL (bundled), file path, or data.frame (scType only)
  - Returns invisible list: $singler (data.frame), $sctype (character vector)

PANDORA_annotate_singler(sce, reference, labels_col="label.main",
                          cluster_col=NULL, assay_name="logcounts",
                          label_col="singler_label", prune=TRUE, verbose=TRUE)
  - Reference-based annotation via SingleR::SingleR()
  - reference: pre-loaded SummarizedExperiment OR shorthand string
    Shorthands: "HumanPrimaryCellAtlas", "BlueprintEncode", "DICE",
                "Monaco", "Novershtern" (human); "ImmGen", "MouseRNAseq" (mouse)
  - cluster_col=NULL: cell-level annotation
  - cluster_col="cluster": aggregate per cluster, broadcast label to cells
  - prune=TRUE: low-confidence labels set to NA via delta-score pruning
  - Stores result in colData(sce)[[label_col]]
  - Requires SingleR (Imports), celldex (Suggests, only for shorthands)

PANDORA_annotate_sctype(sce, tissue, cluster_col="cluster", db=NULL,
                         species="human", ortholog_method="homologene",
                         assay_name="logcounts", label_col="sctype_label",
                         verbose=TRUE)
  - Cluster-level annotation via scType scoring algorithm (implemented natively)
  - tissue: string matching tissueType in scTypeDB (case-sensitive)
  - db=NULL: uses bundled inst/extdata/ScTypeDB_full.xlsx (16 tissues, 268 rows)
  - db: custom data.frame or path to .xlsx/.csv with same column structure
  - species="human": uses DB markers directly (all HGNC symbols)
  - species!="human": converts human markers to target species orthologs via
    orthogene before scoring; reports database used and mapping rate
  - ortholog_method="homologene": offline, fast, common model organisms
    use "gprofiler" for broader species coverage (requires internet)
  - Algorithm: scale per gene → score cells against marker sets →
    aggregate by cluster → assign best-scoring cell type per cluster
  - Scoring: (Σ pos markers - Σ neg markers) / sqrt(n_markers), capped ±10
  - BPCells-aware: subsets to marker genes before converting to dense matrix
  - Verbose output for non-human: shows n_mapped/n_total, %, method used,
    and a WARNING if mapping rate <50%
  - Stores result in colData(sce)[[label_col]]
  - Requires readxl (Suggests, for .xlsx DB reading)
  - Requires orthogene (Suggests, only when species != "human")

pandora_celltypist.R:
---------------------
PANDORA_list_celltypist_models()
  - Fetches CellTypist model registry (requires internet) and prints all models
  - Returns invisible data.frame of model info
  - Runs via basilisk (isolated Python env, no user setup required)

PANDORA_annotate_celltypist(sce, model, majority_voting=TRUE,
                              force_update=FALSE,
                              label_col="celltypist_label",
                              conf_col="celltypist_conf", verbose=TRUE)
  - Cell type annotation via CellTypist pre-trained models
  - Requires "counts" assay (raw counts); normalisation performed in Python:
    scanpy normalize_total(target_sum=1e4) + log1p — exactly what CellTypist
    expects; R-side logcounts normalisation is NOT used or required
  - model: model filename e.g. "Mouse_Whole_Brain.pkl"
  - majority_voting=TRUE: consensus label per over-cluster (recommended)
  - majority_voting=FALSE: per-cell probabilistic prediction + conf_score
  - force_update=FALSE: use cached model; TRUE re-downloads
  - Models cached in ~/.celltypist/ (celltypist default; first use downloads)
  - BPCells-aware: converts to dgCMatrix before passing to Python
  - Python env managed by basilisk (Python 3.11 + celltypist 1.6.3)
  - Stores labels in colData(sce)[[label_col]]
  - Stores confidence in colData(sce)[[conf_col]] when majority_voting=FALSE

PANDORA_assign_labels(sce, labels, cluster_col="cluster", label_col, verbose=TRUE)
  - Manual mapping from cluster IDs to cell type labels
  - labels: named character vector e.g. c("0"="T cell", "1"="B cell")
  - label_col: required — name for the new colData column (no default to
    prevent accidental overwrites)
  - Clusters missing from labels receive NA with a warning
  - Labels for non-existent clusters are reported as a message (not error)
  - Stores result in colData(sce)[[label_col]]

PANDORA_summarise_labels(sce, label_col, cluster_col=NULL, sample_col=NULL,
                          verbose=TRUE)
  - Frequency table of cell type labels (counts + proportions)
  - cluster_col: optional — adds a breakdown of label composition per cluster
  - sample_col: optional — adds a breakdown of label composition per sample
  - Prints top 15 labels (overall) with cell counts and percentages
  - Returns invisible list: $overall, $by_cluster (or NULL), $by_sample (or NULL)

================================================================================
DEPENDENCIES / NOTES
================================================================================
- SingleR (Imports): reference-based annotation
- basilisk (Imports): isolated Python environment management for CellTypist
  Install: BiocManager::install("basilisk")
  First use creates a conda env (~2-3 min); all subsequent calls instant
  Python env: Python 3.11 + celltypist==1.6.3 + scanpy==1.11.1 + anndata==0.11.4
  Version suffix in env name (cauldron_celltypist_1): increment on pin updates
- celldex (Suggests): celldex reference dataset retrieval (shorthand strings)
  Install: BiocManager::install("celldex")
- readxl (Suggests): reading bundled ScTypeDB_full.xlsx
  Install: install.packages("readxl")
- orthogene (Suggests): ortholog conversion for non-human species in scType
  Install: BiocManager::install("orthogene")
  Default method: "homologene" (offline); "gprofiler" for broader coverage
  Warning threshold: <50% mapping rate triggers explicit caution message
- scType algorithm implemented natively — no GitHub source() dependency
- Bundled DB: inst/extdata/ScTypeDB_full.xlsx
  Columns: tissueType, cellName, geneSymbolmore1 (positive markers, comma-sep),
           geneSymbolmore2 (negative markers, comma-sep; NA = none), shortName
  Tissues: Adrenal, Brain, Eye, Heart, Hippocampus, Immune system, Intestine,
           Kidney, Liver, Lung, Muscle, Pancreas, Placenta, Spleen, Stomach, Thymus
- scTypeDB geneSymbolmore2 is NA for 256/268 rows (negative markers are rare)
- Requires clustered data from TALOS (cluster assignments in colData)
- Labels stored in colData(sce)$singler_label / $sctype_label (configurable)
- Automated annotation should always be reviewed manually — treat as a
  starting point, not ground truth
