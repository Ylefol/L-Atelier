talaria_io.R:

TALARIA_load_h5ad(path, use_hdf5=FALSE, reader="R", backend="memory",
                   bpcells_dir=NULL, verbose=TRUE)
  - Loads .h5ad (AnnData/Scanpy) into SingleCellExperiment via zellkonverter
  - X / raw.X -> assay(s); layers -> additional assays; obs -> colData;
    var -> rowData; obsm (X_pca, X_umap, etc.) -> reducedDims
  - Validates and normalises assay names (see .talaria_normalise_assay_names)
  - use_hdf5=TRUE keeps matrices on-disk (HDF5Array) for large datasets
  - reader="R" uses pure rhdf5; reader="python" uses basilisk/anndata
  - backend="bpcells" converts counts to BPCells on-disk store after loading
  - Prints formatted summary; returns SingleCellExperiment

TALARIA_load_10x(path, sample_names=NULL, backend="memory", bpcells_dir=NULL,
                  verbose=TRUE)
  - Loads 10x MEX directory (barcodes/features/matrix) via DropletUtils
  - path: directory containing barcodes.tsv.gz, features.tsv.gz, matrix.mtx.gz
  - backend="bpcells" converts counts to BPCells on-disk store after loading
  - Returns SingleCellExperiment with "counts" assay

TALARIA_load_h5(path, sample_names=NULL, backend="memory", bpcells_dir=NULL,
                 verbose=TRUE)
  - Loads 10x HDF5 (.h5) file via DropletUtils
  - backend="bpcells" converts counts to BPCells on-disk store after loading
  - Returns SingleCellExperiment with "counts" assay

TALARIA_load_loom(path, verbose=TRUE)
  - Loads .loom file via LoomExperiment::import()
  - Returns SingleCellExperiment (SingleCellLoomExperiment subclass)
  - No BPCells backend — legacy format, no direct BPCells reader

TALARIA_to_bpcells(sce, bpcells_dir, assay_name="counts", verbose=TRUE)
  - Converts any in-memory SCE counts assay to on-disk BPCells IterableMatrix
  - Writes to bpcells_dir via BPCells::write_matrix_dir()
  - Re-opens lazily via BPCells::open_matrix_dir()
  - Stores bpcells_dir path in metadata(sce)$bpcells_dir
  - bpcells_dir must be a permanent path (embedded in RDS on save)
  - Use at any pipeline stage to adopt BPCells backend after initial load
  - Requires BPCells (Suggests): devtools::install_github("bnprks/BPCells/r")

TALARIA_to_seurat(sce, counts="counts", data=NULL)
  - Converts SCE to Seurat object via Seurat::as.Seurat()
  - data defaults to "logcounts" if present, otherwise NULL
  - Requires Seurat (Suggests)

TALARIA_from_seurat(sobj, assay="RNA", verbose=TRUE)
  - Converts Seurat object to SCE via Seurat::as.SingleCellExperiment()
  - Applies assay name normalisation after conversion
  - Requires Seurat (Suggests)

TALARIA_export_matrix(sce, output_dir, format="csv", assay_name="counts",
                       verbose=TRUE)
  - format="csv": writes assay as dense CSV (warns if matrix is large)
  - format="mex": writes 10x MEX files via DropletUtils::write10xCounts()
  - Creates output_dir if it does not exist

TALARIA_export_metadata(sce, output_path, verbose=TRUE)
  - Writes colData as CSV with cell_barcode as first column

TALARIA_save_sce(sce, output_path, verbose=TRUE)
  - Serialises SCE to RDS; creates parent directories as needed

TALARIA_load_sce(path, verbose=TRUE)
  - Reads RDS; validates the loaded object is a SingleCellExperiment
  - If SCE was BPCells-backed, the lazy matrix reconnects automatically
    provided bpcells_dir is accessible at the stored path

talaria_logging.R:
------------------
TALARIA_generate_log_filename(log_dir=NULL, prefix="log", extension=".log",
                               format="compact")
  - Generates a timestamp-based log filename (sortable, filesystem-safe)
  - format="compact": YYYY_MM_DD__HH_MM; format="readable": YYYY-MM-DD_HH-MM-SS

TALARIA_start_log(log_file, append=FALSE)
  - Starts duplicating stdout to log_file via sink(split=TRUE)
  - Writes header: start time, R version, platform, working directory
  - Warnings/errors NOT captured (console-only for immediate visibility)
  - Creates parent directories automatically

TALARIA_stop_log()
  - Stops sink, appends session info (end time, duration, sessionInfo())
  - Closes file connection cleanly

TALARIA_is_logging()   — returns TRUE if a log is currently active
TALARIA_get_log_file() — returns current log path, or NULL if inactive

talaria_export.R:

TALARIA_export_de(de_result, output_dir, prefix="de", plots=TRUE,
                   top_n=10L, l2fc_thresh=1, plot_width=8, plot_height=6,
                   verbose=TRUE)
  - Writes one CSV per cluster/group + summary CSV + RDS object
  - Accepts keraunos_markers, keraunos_contrast, or keraunos_pseudobulk
  - plots=TRUE (pseudobulk only): volcano + MA per cluster as PDFs
    (uses native .talaria_plot_volcano / .talaria_plot_ma helpers)
    Labels top_n genes by significance; requires ggrepel (Suggests)
  - Returns invisibly: character vector of file paths written

TALARIA_export_gsea(result, output_dir, prefix="gsea", plots=TRUE,
                     top_n=20L, plot_width=8, plot_height=6,
                     enrich_plot_height=4, verbose=TRUE)
  - Accepts keraunos_gsea or keraunos_gsea_multi
  - Writes results CSV(s) + RDS + (if plots=TRUE):
      dotplot (top_n/2 enriched + top_n/2 depleted by padj; NES on x,
               dot size=gene set overlap, colour=-log10(padj))
      enrichment score plots for top_n pathways (fgsea::plotEnrichment)
  - Multi: per-cluster subdirectory layout
  - Enrichment plots require ranked_genes + gene_sets stored in object
    (stored automatically in keraunos_gsea since last KERAUNOS_gsea update)

TALARIA_export_ora(result, output_dir, prefix="ora", plots=TRUE,
                    top_n=20L, plot_width=8, plot_height=7, verbose=TRUE)
  - Accepts keraunos_ora or keraunos_ora_multi
  - Writes results CSV(s) + RDS + (if plots=TRUE):
      dotplot (top_n terms across sources; fold enrichment on x,
               dot size=intersection_size, colour=-log10(p_value),
               faceted by source)
  - Multi: per-cluster subdirectory; up and down exported separately

TALARIA_export_first_steps(sce, output_dir, hvg_sweep=NULL, pc_sweep=NULL,
                            k_sweep=NULL, resolution_sweep=NULL,
                            umap_sweep=NULL, tsne_sweep=NULL,
                            colour_by="cluster", sample_col=NULL,
                            assay_name="logcounts", format="png", verbose=TRUE)
  - Bundles all outputs of a first-steps pipeline run into a structured dir:
      sce/        — sce.rds (RDS of the SCE object)
      plots/      — all ggplot outputs at 600 DPI (PNG) or vector (PDF)
      tables/     — CSVs: cell_metadata, analysis_parameters, sweep results
  - Auto-detects SCE state: only exports what has been computed
      (PCA, UMAP, TSNE in reducedDims; QC cols in colData; hvg in metadata)
  - Sweep objects passed explicitly — all optional; omitting one simply skips
    its plot and result table
  - analysis_parameters.csv: 2-column table of key analysis choices
      (n_hvgs, n_pcs_used, k, clustering_method, resolution, n_neighbors,
       min_dist, perplexity); NA for parameters whose sweep was not provided
  - BPCells-aware: saveRDS works for both backends (BPCells stores path ref);
    prints a reminder to keep bpcells_dir alongside the RDS
  - colour_by: falls back to first factor/character colData col if not found
  - sample_col: if provided, exports an additional grouped QC plot
  - format="png": 600 DPI; format="pdf": vector (no DPI)
  - Plot sizes: QC 10×(3.5×nrows)"; elbow 8×5"; sweeps 6-7×8-11";
    grids 14×12"; individual UMAP/tSNE 7×6"
  - Returns invisible list: output_dir + files (manifest of all saved paths)
  - Individual plots/tables still accessible via their respective functions

================================================================================
DEPENDENCIES / NOTES
================================================================================
- Primary object: SingleCellExperiment (Bioconductor)
- zellkonverter (Suggests): h5ad loading
- DropletUtils (Suggests): 10x MEX + H5 loading; MEX export
- LoomExperiment (Suggests): loom loading
- Seurat (Suggests): SCE <-> Seurat conversion (not a hard dependency)
- BPCells (Suggests): on-disk bitpacked matrix backend for large datasets
  Install: devtools::install_github("bnprks/BPCells/r")
  All calls via requireNamespace() + BPCells:: prefix (no @importFrom)
- ggrepel (Suggests): gene labels on volcano/MA plots in export_de
- fgsea (Suggests): enrichment score plots in export_gsea (via plotEnrichment)
- Internal helpers in talaria_export.R:
    .talaria_plot_volcano(), .talaria_plot_ma() — native CAULDRON implementations
    (inspired by GAIA/AETHER but no cross-package dependency)
    .talaria_gsea_dotplot() — NES dotplot for fgsea results
    .talaria_ora_dotplot()  — fold enrichment dotplot for gprofiler2 results
    .talaria_gsea_enrichment_plot() — wraps fgsea::plotEnrichment()
- TALARIA owns all CAULDRON exports, paralleling GAIA's ELEUTHIA module
- Entry point for CAULDRON — all other modules depend on a properly loaded SCE
- .talaria_normalise_assay_names(): ensures raw counts assay is named "counts"
  (Bioconductor convention); errors if X is continuous/log-normalised
- .talaria_is_integer_matrix(): block-sample check, safe for HDF5Array
- .talaria_to_bpcells_backend(): internal dispatcher called by loaders;
  validates bpcells_dir is non-NULL, then delegates to TALARIA_to_bpcells()

BPCELLS PIPELINE COMPATIBILITY
================================================================================
Step                      | Compatible | Notes
--------------------------|------------|--------------------------------------
AEGIS_compute_qc_metrics  | YES        | BPCells path via colSums()+matrix_stats();
                          |            | scuttle/beachmat bypassed (no S4Arrays
                          |            | support for IterableMatrix)
AEGIS_detect_doublets     | SKIP       | Skipped by default when BPCells detected;
                          |            | scDblFinder would load full matrix into RAM
                          |            | (OOM risk). Override: force_bpcells=TRUE
PYRI_normalize            | YES        | scater::logNormCounts produces lazy BPCells logcounts
PYRI_select_hvg           | YES        | BPCells path via matrix_stats()+fitTrendVar();
                          |            | scran::modelGeneVar bypassed (beachmat incompat.)
TALOS_run_pca             | YES        | Unified irlba path for ALL backends (.talos_irlba_pca);
                          |            | scater::runPCA no longer used (its BiocSingular wrapper
                          |            | uses different irlba defaults → different PC suggestions;
                          |            | direct irlba gives identical results for memory + BPCells)
TALOS_run_umap/tsne       | YES        | Operates on small dense PCA matrix
TALOS_build_graph/cluster | YES        | Operates on small dense PCA matrix
