talos_tuning.R (PC sweep):
--------------------------
TALOS_tune_pc(sce, n_pcs_range=seq(5,50,by=5), k=20, type="rank",
              method="leiden", resolution=1.0, n_runs=5, seed=42, verbose=TRUE)
  - Sweeps n_pcs by building an SNN graph at each cutoff (no PCA recomputation)
  - Metrics: cum_var (from stored percentVar) + graph modularity
  - n_runs: runs community detection n_runs times per step, averages modularity
    to dampen Leiden/Louvain stochasticity (representative run = closest to mean)
  - Selection: kneedle elbow on modularity curve (downstream-validated)
  - Distinct from ASPIS_plot_elbow: tests graph quality, not PCA statistics alone
  - k/type/method/resolution held fixed — tune those separately afterwards
  - Returns talos_pc_sweep: results df, 2-panel line plot, best_n_pcs, params
  - print.talos_pc_sweep() gives tidy console summary

talos_embedding.R:
------------------
TALOS_run_pca(sce, n_pcs=50, use_hvg=TRUE, assay_name="logcounts",
              scale=FALSE, verbose=TRUE)
  - Runs PCA via .talos_irlba_pca() for ALL matrix backends (unified path)
  - BPCells IterableMatrix: 2 streaming passes for gene means + variances,
    then irlba::irlba() via BiocGenerics::t() (streaming from disk, no RAM load)
  - In-memory dgCMatrix: rowMeans() + one-pass variance, then irlba
  - scater::runPCA() is no longer used — direct irlba ensures identical
    numerical results regardless of backend (scater uses BiocSingular defaults
    that differ from direct irlba, which caused backend-dependent PC suggestions)
  - use_hvg=TRUE uses metadata(sce)$hvg (set by PYRI_select_hvg); warns and
    falls back to all genes if HVGs not found
  - Prints variance explained by first 5 PCs
  - Stored as reducedDims(sce)[["PCA"]] with percentVar and rotation attributes

TALOS_run_harmony(sce, batch_col="sample_id", n_pcs=30, theta=2,
                   max_iter=10, seed=42, verbose=TRUE)
  - Batch integration via harmony::RunHarmony() (SCE dispatch, harmony v2)
  - Operates on reducedDims(sce)[["PCA"]]; corrects clone/sample-level drift
    while preserving genuine between-condition biological variation
  - batch_col: any colData column; use "sample_id" to correct per-sample effects
  - theta: diversity penalty — higher = stronger mixing (default 2 is standard)
  - Stored as reducedDims(sce)[["Harmony"]] (cells x n_pcs)
  - Recommended order: run_pca → run_harmony → build_graph(use_rep="Harmony")
    → cluster → run_umap(use_graph=TRUE)

TALOS_run_umap(sce, use_rep="PCA", n_pcs=30, n_neighbors=15, min_dist=0.1,
               use_graph=TRUE, seed=42, verbose=TRUE)
  - use_graph=TRUE (default): uses the pre-built SNN graph from metadata(sce)$snn_graph
    (set by TALOS_build_graph()) directly as uwot input, bypassing internal KNN;
    n_neighbors is ignored; k is retrieved from metadata(sce)$snn_k; ensures
    clustering and UMAP operate on the same neighbourhood structure (true alignment)
  - SNN weights are normalized to [0,1] before passing to uwot (required for
    rank-based weights; Jaccard weights are already in range)
  - Stored as reducedDims(sce)[["UMAP"]]

TALOS_run_tsne(sce, n_pcs=30, perplexity=30, max_iter=1000, seed=42,
               verbose=TRUE)
  - Runs tSNE via scater::runTSNE() on PCA space
  - Stored as reducedDims(sce)[["tSNE"]]

TALOS_build_graph(sce, n_pcs=30, k=20, type="rank", verbose=TRUE)
  - Builds SNN graph via scran::buildSNNGraph() on PCA space
  - type: edge weight scheme — "rank" (default), "number", "jaccard"
  - Stored as metadata(sce)$snn_graph; k stored as metadata(sce)$snn_k
    (consumed by TALOS_run_umap(use_graph=TRUE) for graph-aligned UMAP)

TALOS_cluster(sce, method="leiden", resolution=1.0, cluster_col="cluster",
               seed=42, verbose=TRUE)
  - Applies community detection to metadata(sce)$snn_graph
  - method: "leiden" (default, better-connected partitions) or "louvain"
  - resolution: controls granularity — higher = more, smaller clusters
  - Stored as colData(sce)[[cluster_col]] (factor)
  - Requires TALOS_build_graph() to have been run first

TALOS_tune_k(sce, k_range=seq(5,50,by=5), n_pcs=30, type="rank",
              method="leiden", resolution=1.0, compute_silhouette=TRUE,
              max_cells_sil=10000, n_runs=5, seed=42, verbose=TRUE)
  - Sweeps k values for SNN graph construction; clusters at each k
  - n_runs: community detection run n_runs times per k, modularity averaged
    (representative run used for silhouette)
  - Metrics per k: n_clusters, modularity (mean), mean silhouette (PCA space)
  - Silhouette skipped automatically when ncol(sce) > max_cells_sil
    (uses modularity for selection instead)
  - Returns talos_k_sweep object: results df, ggplot, best_k, params
  - print.talos_k_sweep() gives a tidy console summary
  - Recommended before committing to a k in TALOS_build_graph()

TALOS_tune_umap(sce, n_neighbors_range=c(10,15,20,30,50),
                 min_dist_range=c(0.05,0.1,0.3,0.5), n_pcs=30, knn_k=15,
                 cluster_col="cluster", use_graph=TRUE, seed=42, verbose=TRUE)
  - use_graph=TRUE (default): n_neighbors is fixed by the SNN graph (k from metadata(sce)$snn_k);
    only min_dist is swept; each run calls uwot::umap(X=adj, ...) directly;
    plot switches to a line plot over min_dist (tile heatmap has no n_neighbors axis)
  - Metrics: KNN overlap (Jaccard, PCA vs embedding) + mean silhouette in 2D
  - Both normalised to [0,1] and averaged into a composite score
  - Silhouette skipped if cluster_col not found in colData
  - Returns talos_embedding_sweep: results df, embeddings list (cells×2 per combo),
    ggplot, best_params (n_neighbors + min_dist), params
  - KNN reference computed once in PCA space via BiocNeighbors::findKNN()

TALOS_tune_resolution(sce, resolution_range=seq(0.1,2.0,by=0.1),
                       method="both", n_pcs=30, compute_silhouette=TRUE,
                       max_cells_sil=10000, n_runs=5, seed=42, verbose=TRUE)
  - Sweeps resolution for Leiden and/or Louvain on the pre-built SNN graph
  - n_runs: community detection run n_runs times per combination, modularity
    averaged (representative run used for silhouette and min_cl_size)
  - Metrics: n_clusters, modularity (mean), mean silhouette (PCA), min_cl_size
  - method="both" runs both algorithms at every resolution for direct comparison
  - PCA distance matrix computed once before the loop (silhouette-efficient)
  - Silhouette skipped when ncol(sce) > max_cells_sil (modularity used instead)
  - Returns talos_resolution_sweep: results df, multi-panel line plot,
    best_params (overall), best_per_method (per algorithm), params
  - Plot: 4 panels (n_clusters/modularity/silhouette/min_cl_size), two
    coloured lines (leiden=#4E79A7, louvain=#F28E2B), dashed vlines at best
    resolution per method
  - print.talos_resolution_sweep() gives tidy console summary
  - Requires TALOS_build_graph() to have been run first

TALOS_tune_tsne(sce, perplexity_range=c(10,20,30,50,100), n_pcs=30,
                 max_iter=1000, knn_k=15, cluster_col="cluster",
                 seed=42, verbose=TRUE)
  - Sweeps perplexity for tSNE; max_iter is fixed (not a tuning target)
  - Same metrics as TALOS_tune_umap; perplexity > N/3 automatically removed
  - Returns talos_embedding_sweep: results df, embeddings list (cells×2 per combo),
    line plot ggplot, best_params (perplexity), params
  - Embedding matrices stored in sweep$embeddings for use by ASPIS_plot_embedding_grid
  - Shared S3 class with TALOS_tune_umap; print.talos_embedding_sweep()

- SNN graph stored in metadata(sce)$snn_graph (consumed by TALOS_cluster)
