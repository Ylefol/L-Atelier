IMPLEMENTED FUNCTIONS

matrix_utils.R:
---------------
DEMETER_matrix_power(x, n)
  - Compute matrix power using eigendecomposition
  - Used for covariance matrix operations (e.g., Sigma^(-0.5))

DEMETER_gettingInverse(X, tolerance)
  - Compute pseudoinverse with tolerance for near-zero eigenvalues
  - Handles singular/near-singular matrices

%^% operator
  - Infix operator for matrix power (Sigma %^% (-0.5))

grid_utils.R:
-------------
DEMETER_create_coarse_grid(n_params, values)
  - Create coarse grid for initial hyperparameter search
  - Returns all combinations of specified values

DEMETER_create_fine_grid(ranges, n_points)
  - Create fine grid within specified ranges
  - For refined search after coarse grid identifies promising region

DEMETER_create_ranges_around_values(best_values, coarse_values, width_factor)
  - Generate ranges around best values from coarse search
  - Helper for two-stage grid search workflow

simulate_data.R:
----------------
DEMETER_generate_multi_datasets(n_datasets, n_samples, n_features,
                                 signal_samples, signal_features, seed)
  - Generate synthetic multi-omics data for testing sCCA methods
  - Creates correlated signal regions across datasets

correlation_utils.R:
--------------------
DEMETER_correlation_matrix(data, method, alternative, adjust, use)
  - Calculate pairwise correlation matrix with p-values
  - Methods: spearman, pearson, kendall
  - Optional p-value adjustment (BH, bonferroni, etc.)
  - Returns: correlation, pvalue, padj (optional), n matrices

DEMETER_format_pvalues(pvalues, format, digits, sig_threshold, hide_ns, ns_string)
  - Format p-values for display
  - Formats: "scientific", "stars", "decimal", "hybrid"
  - Option to hide non-significant values
  - Works with vectors or matrices

DEMETER_format_pvalue_triangle(pvalue_matrix, triangle, format, sig_threshold, hide_ns)
  - Format p-values for triangular correlation plots
  - Keeps upper or lower triangle, blanks rest
