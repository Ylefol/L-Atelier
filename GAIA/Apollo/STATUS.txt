annotation.R:
-------------
APOLLO_get_chr_mapping(genome)
  - Get chromosome name mapping for specific genome
  - Currently supports: "T2T" (T2T-CHM13v2.0)
  - Returns named vector: NCBI accession -> UCSC name

APOLLO_get_chromosome_sizes(annotation_path, chromosomes, name_mapping,
                             add_chr_prefix, cache_dir, cache_name, force, verbose)
  - Extract chromosome sizes from GTF/GFF annotation
  - Supports gzipped files
  - Uses ##sequence-region pragmas if available (GFF3)
  - Caching: saves to ZERO_DAWN/data/ as RDS for fast reload
  - Cache filename includes name_mapping (e.g., _T2T suffix)
  - force=TRUE to regenerate cache
  - Returns data.frame: chr, size

APOLLO_chr_sizes_to_seqinfo(chr_sizes, genome)
  - Convert chr_sizes data.frame to Seqinfo object
  - For compatibility with GenomicRanges/Bioconductor

APOLLO_sequence_composition(regions, fasta_path, chr_mapping, extend, min_width,
                             include_repeats, include_sequence, verbose)
  - Calculate GC/AT content for genomic regions
  - Detects homopolymer runs (e.g., AAAA) and dinucleotide repeats (e.g., ATATAT)
  - chr_mapping: "T2T" or custom vector to translate region chr names to FASTA names
    (e.g., chr1 -> NC_060925.1 for T2T FASTA files)
  - extend: bp to add on EACH side (consistent with ELEUTHIA_expand_regions)
  - min_width: regions below threshold return NA (default 100bp)
  - include_sequence: whether to include sequence column in output (default TRUE)
  - Compatible with ELEUTHIA_select_regions output
  - Returns: gc_percent, at_percent, n_count, repeat statistics, optionally sequence

peak_annotation.R:
------------------
APOLLO_make_txdb(gtf_path, cache_dir, cache_name, chr_mapping, organism,
                  force, verbose)
  - Create TxDb from GTF/GFF annotation file
  - Automatic caching to ZERO_DAWN/data/ as SQLite (uses AnnotationDbi::saveDb)
  - chr_mapping: "T2T" for built-in NCBI->UCSC renaming, or custom named vector
  - Useful for non-standard genomes like T2T-CHM13
  - One-time slow creation, fast subsequent loads

APOLLO_annotate_peaks(regions, txdb, tss_region, level, verbose)
  - Annotate peaks with genomic features using ChIPseeker
  - Returns: annotation (Promoter/Exon/Intron/etc.), gene_id, distance_to_tss
  - Simplified annotation categories for easy filtering
  - Works with any TxDb (including custom T2T)

APOLLO_enrich_go(annotated_peaks, org_db, ont, gene_id_type, pval_cutoff,
                  qval_cutoff, min_gs_size, max_gs_size, verbose)
  - GO enrichment analysis using clusterProfiler
  - Supports BP, MF, CC, or ALL ontologies
  - Auto-converts gene IDs (SYMBOL, ENSEMBL) to ENTREZID
  - Returns enrichResult object (dotplot, barplot, cnetplot methods)

APOLLO_enrich_kegg(annotated_peaks, org_db, organism, gene_id_type,
                    pval_cutoff, qval_cutoff, verbose)
  - KEGG pathway enrichment analysis
  - Same interface as APOLLO_enrich_go

gene_enrichment.R:
------------------
APOLLO_convert_genes(genes, org_db, from_type, to_type, strip_version, verbose)
  - Convert gene IDs with fallback to original when conversion fails
  - Ideal for count matrix rownames (preserves all genes)
  - strip_version: removes Ensembl version suffixes (default TRUE)
  - Unmapped genes keep their (stripped) original ID
  - Handles duplicates by adding suffix (e.g., "TP53.1")
  - Example: rownames(counts) <- APOLLO_convert_genes(rownames(counts), org.Hs.eg.db)

APOLLO_prepare_genelist(genes, org_db, from_type, to_type, strip_version,
                         drop_na, verbose)
  - Convert gene symbols to ENTREZID (or other ID types)
  - Works with single vector or named list (e.g., module gene lists)
  - strip_version: removes Ensembl version suffixes (ENSG00000141510.16 -> ENSG00000141510)
  - org_db can be NULL to just clean IDs without conversion
  - Reports conversion statistics

APOLLO_extract_module_genes(modules, modules_of_interest, exclude_grey,
                             strip_version, org_db, from_type, to_type, verbose)
  - Extract gene lists from wgcna_modules object
  - strip_version: for Ensembl IDs with version numbers (e.g., for gprofiler)
  - Optionally convert to ENTREZID if org_db provided
  - from_type/to_type: control ID conversion (default ENSEMBL -> ENTREZID)
  - Convenience wrapper for WGCNA workflows

APOLLO_enrich_gost(gene_lists, organism, sources, user_threshold, correction_method,
                    domain_scope, custom_bg, min_term_size, max_term_size, significant,
                    exclude_iea, verbose)
  - Functional enrichment using gprofiler2::gost()
  - Accepts multiple ID types directly (ENSEMBL, SYMBOL, etc.) - no conversion needed
  - Sources: GO:BP, GO:MF, GO:CC, KEGG, REAC (Reactome), WP (WikiPathways),
             TF (TRANSFAC), MIRNA, CORUM, HP (Human Phenotype)
  - Returns combined results with 'module' and 'source' columns
  - correction_method: "g_SCS" (default), "fdr", "bonferroni"
  - organism: "hsapiens", "mmusculus", etc.

APOLLO_filter_enrichment(enrich_result, sources, modules, top_n)
  - Filter gost_enrichment results by source (e.g., "KEGG") or module
  - top_n: keep top N terms per module per source

DEPENDENCIES

- Uses: APOLLO_get_chr_mapping (for chromosome renaming in make_txdb)

  - txdbmaker (for makeTxDbFromGFF - modern replacement for GenomicFeatures)
  - AnnotationDbi (for saveDb/loadDb of TxDb objects)
  - GenomicFeatures (for genes/transcripts queries)
  - ChIPseeker (for peak annotation)
  - clusterProfiler (for peak_annotation GO/KEGG enrichment)
  - gprofiler2 (for gene list enrichment - more flexible, no ENTREZID required)
  - org.Hs.eg.db (human gene annotation, or other org.Db)
  - Rsamtools (for FASTA file access in sequence_composition)
  - Biostrings (for sequence extraction and manipulation)
  - GenomicRanges/IRanges (for GRanges coordinate handling)
