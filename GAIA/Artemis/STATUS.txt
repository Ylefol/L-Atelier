anchor_analysis.R:
------------------
ARTEMIS_global_shift_test(quant_result, group_col, group_a, group_b,
                           summary_method, test, pseudocount, verbose)
  - Test for systematic signal shift at anchor regions between conditions
  - Paired Wilcoxon or t-test across all regions
  - Returns per-region log2FC and global p-value
  - Answers: "Is there an overall effect at these sites?"

ARTEMIS_plot_global_shift(shift_result, plot_type, highlight_threshold, title)
  - Visualize global shift results
  - Density plot of log2FC distribution
  - Paired dot plot showing per-region changes
  - Returns ggplot object(s)

differential_analysis.R:
------------------------
ARTEMIS_normalize_counts(counts, targets, group_col, batch_col, verbose)
  - Normalize count data using DESeq2 size factors
  - Estimates size factors on FULL dataset ONCE
  - For multi-comparison workflows: normalize first, then run multiple DEA
  - Returns "artemis_norm" object with: dds, norm_counts, targets, size_factors
  - Ensures consistent normalization across all subsequent comparisons

ARTEMIS_differential_counts(quant_result, reference, experiment,
                             group_col, batch_col, alpha, verbose)
  - General-purpose differential analysis using DESeq2
  - Works with any count data: RNA-seq, ATAC-seq, CUT&TAG, ChIP-seq
  - Accepts two input types:
    - quant_result (list with counts + targets): standard single comparison
    - artemis_norm object: uses pre-computed size factors, subsets to groups
  - Strict two-group comparison (reference vs experiment)
  - Optional batch correction via design formula (~ batch + group)
  - Validates: exactly 2 groups, minimum 2 replicates each, integer counts
  - Returns: per-feature stats (log2FC, pvalue, padj), DESeqDataSet, norm_counts, summary

ARTEMIS_select_de_genes(de_results, l2fc_thresh, p_col, p_thresh, gene_col, union, verbose)
  - Collect significant genes across DE comparisons (union or intersection)
  - Accepts multiple input types:
    - artemis_ts_de objects (time series DEA)
    - DEA result from ARTEMIS_differential_counts()
    - Raw data.frame with gene IDs and DE stats
    - Lists of any combination
  - Auto-detects gene ID column (gene_id, feature_id, etc.) or specify with gene_col
  - Returns character vector with gene_summary and per_comparison attributes

ARTEMIS_prepare_part_matrix(de_result, genes, samples, scale, log_transform, verbose)
  - Prepare expression matrix for PART clustering from DEA results
  - Extracts normalized counts from:
    - artemis_norm objects (from ARTEMIS_normalize_counts)
    - DEA result from ARTEMIS_differential_counts() (from DESeqDataSet)
    - artemis_ts_de objects (from norm_counts)
    - Raw numeric matrix
  - Subsets to selected genes, optional sample subsetting
  - log_transform: applies log2(x+1) (default FALSE, matches original TiSA)
  - scale: z-score each gene across samples (default TRUE)
  - Returns matrix ready for ARTEMIS_part()

utils.R:
--------
ARTEMIS_distance_to_nearest(query_regions, subject_regions,
                             query_id_col, subject_id_col, verbose)
  - Calculate distance from each query region to nearest subject region
  - Wraps GenomicRanges::distanceToNearest() with data.frame interface
  - Returns: distance, overlap status, and nearest feature ID per query
  - Useful for checking peak overlap (e.g., ChIP anchors at ATAC peaks)

famd.R:
-------
ARTEMIS_famd(data, na_action, na_threshold, ncp, sup_quanti, sup_quali,
             ncp_impute, prefix_levels, verbose)
  - Factor Analysis of Mixed Data (FAMD) for dimensionality reduction
  - Handles datasets with both quantitative and qualitative variables
  - NA handling: "fail" (strict), "omit" (drop rows), "impute" (missMDA)
  - Automatic column dropping for high NA proportion (na_threshold)
  - prefix_levels: auto-prefix factor levels with variable names (e.g., "0" -> "gender_0")
    prevents ambiguity when multiple factors have overlapping numeric levels
  - Returns: eigenvalues, individual coords/cos2/contrib, variable results, level_mapping
  - Class "artemis_famd" with print method

clustering.R:
-------------
ARTEMIS_cluster_mixed(data, k, k_range, method, hclust_method, stand, verbose)
  - Clustering for mixed (quantitative + qualitative) data
  - Uses Gower distance (handles mixed types natively)
  - Methods: "pam" (partitioning around medoids) or "hierarchical"
  - Auto-selection of k using silhouette scores
  - When k="auto": returns k_evaluation with assignments at each k and transitions
    for Sankey visualization (pass to AETHER_plot_cluster_sankey)
  - Returns: cluster assignments, silhouette info, k_selection, k_evaluation, medoids
  - Class "artemis_cluster" with print method

ARTEMIS_cluster_stability(cluster_result, n_boot, verbose)
  - Bootstrap-based stability assessment for clustering
  - Measures how consistent cluster assignments are under resampling
  - Returns: Jaccard similarity (overall and per-cluster), sample stability
  - Interpretation guide for stability scores

ARTEMIS_characterize_clusters(cluster_result, data, p_adjust, verbose)
  - Determine which variables best discriminate between clusters
  - Quantitative: Kruskal-Wallis test + eta-squared effect size
  - Qualitative: Chi-square test + Cramér's V effect size
  - Returns ranked table by effect size, cluster profiles for top variables
  - Effect size interpretation (small/medium/large)

ARTEMIS_compare_variable_importance(cluster_char, famd_result, n_dims,
                                     low_threshold, verbose)
  - Compare variable importance from clustering vs FAMD
  - Combines effect sizes (from characterization) with FAMD contributions
  - Computes percentile ranks for both metrics
  - Flags variables low on BOTH as removal candidates
  - Aggregates qualitative contributions from category to variable level
  - Returns: comparison table, low_signal list, high_signal list
  - For iterative variable refinement in Phase 3 of pipeline

ARTEMIS_evaluate_k_range(data, k_range, method, hclust_method, stand, verbose)
  - Standalone k evaluation (alternative to using cluster_mixed with k="auto")
  - Use when: you have a pre-computed distance matrix, or want to evaluate
    without committing to final clustering
  - Returns: metrics (silhouette per k), assignments (samples x k), transitions
  - transitions data feeds into AETHER_plot_cluster_sankey()
  - Class "artemis_k_evaluation" with print method
  - Note: ARTEMIS_cluster_mixed(k="auto") now includes k_evaluation in output

.match_cluster_labels(clust1, clust2)
  - Internal helper to handle label switching in bootstrap comparisons

.test_quanti_cluster(x, clusters)
  - Internal: Kruskal-Wallis + eta-squared for quantitative variables

.test_quali_cluster(x, clusters)
  - Internal: Chi-square + Cramér's V for qualitative variables

discriminative_analysis.R:
--------------------------
ARTEMIS_fit_group_lasso(X, y, groups, family, penalty, nlambda, lambda,
                         alpha, group_names, verbose)
  - Fits Group LASSO for variable selection in mixed data
  - Treats all dummy columns from one categorical as a group
  - Penalties: grLasso (default), grMCP, grSCAD
  - Families: binomial, multinomial, gaussian, poisson
  - Returns fitted model with regularization path
  - Requires: grpreg package

ARTEMIS_select_lambda(glasso_fit, X, y, nfolds, seed, verbose)
  - Cross-validation to select optimal lambda (regularization strength)
  - Returns lambda.min (minimum CV error) and lambda.1se (parsimonious)
  - Counts groups selected at each lambda
  - Recommendation: use lambda.1se for variable selection

ARTEMIS_extract_selected_variables(glasso_fit, lambda, verbose)
  - Identifies which variable groups have non-zero coefficients
  - Returns selected variable names and group numbers
  - Shows coefficient info for quantitative, active levels for categorical
  - Use with cv_result$lambda.1se or cv_result$lambda.min

ARTEMIS_fit_final_model(data, target_var, selected_vars, family, verbose)
  - Fits unpenalized regression on selected variables only
  - Provides unbiased coefficients with valid p-values and CIs
  - Uses original data.frame (not encoded matrix)
  - Families: binomial, multinomial (via nnet), gaussian
  - Returns glm/multinom object for standard R model inspection

ARTEMIS_extract_coefficients(final_model, format, conf_level, digits, verbose)
  - Extracts coefficients in publication-ready format
  - Converts to odds ratios for logistic regression (default)
  - Includes confidence intervals and significance stars
  - Supports multinomial: outputs one row per variable-class combination
  - Returns data.frame suitable for tables/export

wgcna.R:
--------
ARTEMIS_wgcna_prepare(counts, traits, counts_format, sample_col, gene_col,
                       transpose, remove_zero_variance, verbose)
  - Prepare data for WGCNA analysis
  - Accepts pre-loaded data (matrix/data.frame) OR file paths
  - Integrates with ELEUTHIA loading functions
  - Aligns samples between expression and traits
  - Converts traits to numeric (categorical -> factor codes)
  - Removes zero-variance genes
  - Returns "wgcna_data" object with datExpr, datTraits, metadata

ARTEMIS_wgcna_qc(wgcna_data, verbose)
  - Quality control for WGCNA data
  - Wraps WGCNA::goodSamplesGenes()
  - Removes genes/samples with too many missing values or zero variance
  - Updates wgcna_data object in place

ARTEMIS_wgcna_cluster_samples(wgcna_data, method, cut_height, min_cluster_size,
                               plot, verbose)
  - Hierarchical clustering of samples
  - Multiple clustering methods: "average", "complete", "ward.D2", etc.
  - Optional outlier removal via cut_height parameter
  - Generates dendrogram plot
  - Returns "wgcna_cluster" object

ARTEMIS_wgcna_pick_power(wgcna_data, powers, power_auto, r2_cutoff,
                          mean_k_cutoff, network_type, plot, verbose)
  - Soft threshold power selection for network construction
  - AUTO-SELECTION: Automatically picks power using heuristics:
    1. WGCNA's powerEstimate (if available and meets threshold)
    2. First power where R² >= r2_cutoff (default 0.80)
    3. Best available with warning if threshold not met
  - Optional connectivity adjustment
  - Generates diagnostic plots (scale independence + mean connectivity)
  - Returns "wgcna_power" object with power, fit_indices, recommendation

ARTEMIS_wgcna_detect_modules(wgcna_data, power, network_type, tom_type,
                              min_module_size, merge_cut_height, reassign_threshold,
                              max_block_size, n_threads, save_tom, tom_file_base, verbose)
  - Core module detection using blockwiseModules
  - Accepts power as number, wgcna_power object, or NULL (auto-select)
  - Configurable: network/TOM type, module size, merge threshold, threads
  - Auto-detects and fixes WGCNA cor() masking issue (e.g., from org.Hs.eg.db)
  - Returns "wgcna_modules" object with:
    - module_names: gene -> "module_1" (generic identifier, numbered by size)
    - module_labels: gene -> numeric label (0=unassigned, 1=largest, ...)
    - module_colors: module_name -> hex display color (decoupled from name)
    - color_names: module_name -> WGCNA color name (for reference)
    - module_eigengenes: MEs with columns MEmodule_1, MEmodule_2, ...
    - module_summary: module, n_genes, color_name
    - gene_module_df: gene, module_name, module_label, color_name
    - net: raw blockwiseModules output

ARTEMIS_wgcna_module_traits(modules, traits, cor_method, p_adjust, verbose)
  - Correlate module eigengenes with sample traits
  - Pearson or Spearman correlation
  - Multiple testing correction (default: BH)
  - Returns "wgcna_trait_cor" object with:
    - cor_matrix, pvalue_matrix, padj_matrix
    - significant_associations table

ARTEMIS_wgcna_gene_significance(modules, traits, trait_name, cor_method, verbose)
  - Calculate gene significance (GS) and module membership (MM)
  - GS: correlation of each gene with traits
  - MM: correlation of each gene with module eigengene
  - Returns "wgcna_gene_sig" object with:
    - gene_info: full table with GS, MM, p-values
    - by_module: gene lists organized by module
    - top_genes_per_module: ranked gene lists

ARTEMIS_wgcna_hub_genes(modules, gene_sig, trait_name, n_top, mm_threshold,
                         gs_threshold, verbose)
  - Identify hub genes (highly connected within module)
  - Criteria: high module membership (MM >= 0.8 default)
  - Optional: combine with gene significance for trait-relevant hubs
  - Returns "wgcna_hubs" object with:
    - hub_genes: all hub genes meeting criteria
    - by_module: hub genes per module
    - hub_summary: summary table

timeseries_analysis.R:
----------------------
ARTEMIS_normalize_timeseries(counts, targets, group_col, time_col, batch_col, verbose)
  - CRITICAL: First step for time series DEA - normalizes full dataset ONCE
  - Creates DESeqDataSet, estimates size factors on ALL samples
  - MUST be called before conditional/temporal DEA for statistical soundness
  - Returns "artemis_ts_norm" object with dds, norm_counts, size_factors

ARTEMIS_timeseries_conditional(ts_norm, reference, experiment, alpha, verbose)
  - Conditional DEA: compare two groups at each timepoint
  - REQUIRES artemis_ts_norm from ARTEMIS_normalize_timeseries() (not raw counts)
  - Subsets DESeq2 object (preserves pre-computed size factors)
  - Returns "artemis_ts_de" object with per-timepoint results, summary, norm_counts

ARTEMIS_timeseries_temporal(ts_norm, comparisons, alpha, verbose)
  - Temporal DEA: compare timepoints pooling ALL groups together
  - Extracts pure temporal effect independent of condition
  - REQUIRES artemis_ts_norm from ARTEMIS_normalize_timeseries() (not raw counts)
  - comparisons: "consecutive" (TP2 vs TP1, TP3 vs TP2) or "all" (all pairs)
  - Returns "artemis_ts_de" object with norm_counts

cibersort.R:
------------
ARTEMIS_cibersort(mixture, cibersort_path, sig_matrix, perm, QN, verbose)
  - CIBERSORT immune cell deconvolution wrapper
  - Sources original CIBERSORT.R (unmodified) and calls its functions
  - Accepts R objects directly: matrix, data.frame, artemis_norm, artemis_ts_norm
  - Also accepts file path for mixture input
  - Runs in temp directory to contain CIBERSORT's side-effect output file
  - perm: permutations for p-values (default 0, set 100+ for testing)
  - QN: quantile normalization (TRUE for microarray, FALSE for RNA-seq)
  - Returns "artemis_cibersort" S3 object:
    - proportions: samples x cell types matrix (rows sum to 1)
    - p_values: per-sample (NULL if perm=0)
    - correlations: Pearson correlation per sample
    - rmse: RMSE per sample
    - raw: full original CIBERSORT output
    - metadata: parameters, cell type names, timing
  - Requires: CIBERSORT.R source file + signature matrix (e.g., LM22.txt)
  - CIBERSORT dependencies: e1071, parallel, preprocessCore

================================================================================
NOTES
================================================================================
- First functions added: anchor-based analysis for ChIP-anchored workflows
- Will handle statistical inference separate from ML validation (Minerva)
- WGCNA cor() masking: Packages like org.Hs.eg.db can mask WGCNA's custom cor()
  function, causing "unused arguments (weights.x, weights.y, cosine)" errors.
  ARTEMIS_wgcna_detect_modules auto-detects and fixes this by assigning
  WGCNA::cor to the global environment.
- Time series DEA workflow: Size factors MUST be estimated on full dataset once,
  then subsets use those pre-computed size factors. This is enforced by requiring
  ARTEMIS_normalize_timeseries() before conditional/temporal DEA. Creating new
  DESeq2 objects per comparison (with independent normalization) is statistically
  unsound and not supported.
