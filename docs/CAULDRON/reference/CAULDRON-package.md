# CAULDRON: Single-Cell and Single-Nuclei RNA-seq Analysis Toolkit

Modular pipeline for single-cell and single-nuclei RNA-seq analysis
including quality control, preprocessing, dimensionality reduction,
clustering, annotation, differential expression, trajectory analysis,
cell-cell communication, and visualization. Built on
SingleCellExperiment (Bioconductor). Named after figures from Greek
mythology (Hephaestus's creations).
