# CAULDRON ggplot2 theme

A clean, publication-ready ggplot2 theme: white background, subtle grey
gridlines and borders, no minor grid, and bold plot titles. Use as a
drop-in replacement for `theme_bw()`.

## Usage

``` r
KHALKOS_theme_cauldron(base_size = 11, base_family = "")
```

## Arguments

- base_size:

  Numeric. Base font size in points. Default `11`.

- base_family:

  Character. Base font family. Default `""`.

## Value

A ggplot2 `theme` object.
