# Build the REDItools2 CLI argument vector

Build the REDItools2 CLI argument vector

## Usage

``` r
.cyan_reditools_build_args(
  bam,
  reference,
  output_file,
  strand_mode,
  min_coverage,
  min_base_quality,
  min_read_quality,
  min_read_length,
  min_edits,
  strict,
  region,
  omopolymeric_file,
  splicing_file,
  bed_file,
  debug
)
```
