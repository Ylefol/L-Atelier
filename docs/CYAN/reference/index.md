# Package index

## Validation utilities

Pre-flight checks for BAMs, reference files, and the GATK executable.

- [`CYAN_check_bam()`](https://ylefol.github.io/L-Atelier/CYAN/reference/CYAN_check_bam.md)
  : Validate a BAM file
- [`CYAN_check_references()`](https://ylefol.github.io/L-Atelier/CYAN/reference/CYAN_check_references.md)
  : Validate reference files
- [`CYAN_resolve_gatk()`](https://ylefol.github.io/L-Atelier/CYAN/reference/CYAN_resolve_gatk.md)
  : Resolve the GATK executable path

## RNA editing detection

RNA editing (e.g. A-to-I) detection via REDItools2.

- [`CYAN_run_reditools()`](https://ylefol.github.io/L-Atelier/CYAN/reference/CYAN_run_reditools.md)
  : Run REDItools2 RNA editing detection
- [`CYAN_run_reditools_batch()`](https://ylefol.github.io/L-Atelier/CYAN/reference/CYAN_run_reditools_batch.md)
  : Run REDItools2 on multiple samples
