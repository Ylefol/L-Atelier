# Quick Summary of Stratification Results

Print a quick one-page summary of stratification results without file
export. Useful for interactive exploration.

## Usage

``` r
ELEUTHIA_quick_summary(
  cluster_result,
  stability_result = NULL,
  char_result = NULL
)
```

## Arguments

- cluster_result:

  An artemis_cluster object.

- stability_result:

  Optional. An artemis_stability object.

- char_result:

  Optional. An artemis_characterization object.

## Value

Invisibly returns NULL.
