# GAIA: Multi-Omics Integration Toolkit for CUT&TAG, ATAC-seq, and RNA-seq

Modular pipeline for multi-omics analysis including quality control,
preprocessing, annotation, enrichment, integration, machine learning,
statistical analysis, visualization, and reporting. Named after the
subordinate functions from Horizon Zero Dawn.
