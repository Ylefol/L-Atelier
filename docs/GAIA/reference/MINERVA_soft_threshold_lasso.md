# Apply Soft-Thresholding with LASSO Penalty

Soft-thresholding operator for LASSO (L1) penalty. Shrinks values toward
zero by threshold tau.

## Usage

``` r
MINERVA_soft_threshold_lasso(x, tau)
```

## Arguments

- x:

  Input value or vector

- tau:

  Threshold parameter (sparsity level)

## Value

Soft-thresholded value(s)
