# Filter circos data to specific PART clusters

Filter circos data to specific PART clusters

## Usage

``` r
DEMETER_filter_circos_clusters(circos_data, selected_clusters)
```

## Arguments

- circos_data:

  A `part_wgcna_circos` object.

- selected_clusters:

  Character vector of cluster names to keep.

## Value

Updated `part_wgcna_circos` object.
