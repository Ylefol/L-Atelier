L-Atelier

A multi-omics toolkit spanning upstream processing through downstream analysis for bulk and single-cell data — four packages, each covering a stage of the workflow.

Bulk multi-omics

GAIA

Quality control, preprocessing, annotation, enrichment, integration, machine learning, statistics, visualization, and reporting for bulk-level omics. Nine subordinate modules, named after figures from Greek mythology.

Upstream processing

HORIZON

QC, adapter trimming, alignment, BAM processing, read counting, and BigWig generation — produces outputs GAIA and CAULDRON already know how to import. A flat collection of wrappers, no sub-modules.

About this toolkit

L-Atelier (French for the workshop) is a personal toolkit tailored to its author's own workflows — parameters are exposed or hidden based on that use, not a general-audience API design. It's split into four packages to keep development and installation independent: pull in only the package a given analysis needs. Much of the naming convention is derived from the Horizon video game series.

Developed and tested on Ubuntu 24.04 LTS. Cross-platform behaviour on macOS/Windows/other Linux distributions hasn't been verified.
